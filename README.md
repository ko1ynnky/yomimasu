# /yomimasu

競技かるたの読みに手を挙げられずにいる選手が、家で読んで測り、次に直す1点を知るための Web アプリと Agent Skill です。

開発中です。Built with Claude: Japan 2026 の期間中に、このリポジトリで新しく作っています。

## 触り方

公開したら、ここに URL と、マイクを使わずに結果まで見る手順を書きます。
