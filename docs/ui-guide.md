# /yomimasu の UI/UX ガイド

画面を作る PR はこのガイドに従う。見本は [ui-sample.html](ui-sample.html) で、ファイルを開くだけで動く。音は出ず、録音もしない。

## 1. 考え方

文章と見本が違うときは文章に従う。文章にない見た目は見本に合わせる。どちらにもなければ、PR に判断と理由を書く。

| 決まり | 実装で意味すること |
| --- | --- |
| 主役は歌と帯である | 読む画面に飾りを足さない。ボタンは歌の下に置く |
| コマンドは見た目で、AI は動いていない | 「考え中」「考えました」を出さない。待たせる演出を足さない |
| 1画面で押してほしいものは1つである | 塗りのボタンは1画面に1つにする |
| 測っていないものを測ったように見せない | 総合点、明瞭さ、声の大きさの良し悪しを出さない。測れなければ「測れませんでした」と出す |
| 初めての人を止めない | 失敗の表示にも次の操作を置く。ログイン、登録、インストールを求めない |

## 2. 配色

地は明るくする。暗い配色は作らない。`<meta name="color-scheme" content="light">` を入れる。

| 名前 | 値 | 使う所 |
| --- | --- | --- |
| `--paper` | `#F6F2E9` | ページの地 |
| `--card` | `#FFFDF9` | カード、歌詞の面、朱の上の文字 |
| `--ink` | `#201D19` | 本文、線の強いボタン |
| `--ink-2` | `#4B453B` | 説明の文 |
| `--ink-3` | `#655D50` | 補足、標準の値 |
| `--rule` | `#D9D0BF` | カードの線、弱いボタンの線 |
| `--rule-2` | `#E7E0D2` | カードの中の区切り線 |
| `--track` | `#ECE6D8` | 帯の未到達の部分 |
| `--shu` | `#B23A1C` | 塗りのボタン、`>`、伸ばす印、読み終えた文字、録音の丸 |
| `--shu-deep` | `#9C3014` | 小さい朱の文字、注意の判定 |
| `--shu-soft` | `#FAEBE3` | 次に直す項目の行、直す点の表示 |
| `--seg-shimo` | `#B8DCB2` | 帯の下の句 |
| `--seg-yoin` | `#F6D56E` | 帯の余韻 |
| `--seg-ma` | `#F3B283` | 帯の間 |
| `--seg-kami` | `#A6C2EC` | 帯の上の句 |

- 帯の4色は区間にだけ使う。色だけで伝えず、必ず区間の名前を添える。
- 判定を赤と緑で塗らない。色を付ける行は、次に直す1点に選ばれた1行だけである。
- 朱は Claude の製品の色に寄せない。Anthropic のロゴと、公式の製品に見えるマークを使わない。

文字と地の組み合わせは、見本の値で計算してすべて 4.5:1 以上である。最も低いのは `--shu` と `--track` の 4.80:1 で、帯の面に朱の小さい文字を置かない。

## 3. 文字

歌だけをはんなり明朝で出し、ほかは端末の書体を使う。

| 名前 | 書体の並び | 使う所 |
| --- | --- | --- |
| `--f-uta` | `"yomimasu-uta", var(--f-serif)` | 歌（本文、ふりがな、伸ばす印、決まり字） |
| `--f-sans` | `"Hiragino Sans", "Hiragino Kaku Gothic ProN", "Noto Sans CJK JP", "Noto Sans JP", "Yu Gothic", system-ui, sans-serif` | 本文、ボタン |
| `--f-serif` | `"Hiragino Mincho ProN", "Noto Serif CJK JP", "Noto Serif JP", "Yu Mincho", serif` | 見出し、次に直す1点 |
| `--f-mono` | `ui-monospace, "SF Mono", Menlo, "Roboto Mono", monospace` | コマンド、数値 |

はんなり明朝の決まり：

- 歌に限る理由：歌の字は札の読みの表で閉じているので、使う字だけを切り出せて、ファイルが小さい。見出しや説明に広げると、文章を直すたびに切り出しを作り直すことになる。
- 規約は IPA Font License v1.0 である。切り出したものは派生フォントになるので、名前を元と違う `yomimasu-uta` にする。
- 切り出す字は、札の読みの表の本文と仮名（序歌を含む）、ひらがな全体、`ー` とする。ふりがなを足しても切り出しを作り直さずに済む。
- 切り出したファイルは同じオリジンから配信する。外のフォント配信は使わない。
- フォントを置く PR で、規約の全文をフォントの隣に置き、`NOTICE.md` に元のフォントの名前、版、入手先、切り出し方を書く。切り出しの道具を依存に足すときは、理由を PR に書く。
- 太さは1つしかないので、歌は `font-weight: 400`、`font-synthesis: none` にする。合成した太字は線がつぶれる。
- 読む画面では、録音を始める前に `document.fonts.load` で読み込みを終える。録音中に書体が替わると歌詞の位置が動く。読み込めなければ `--f-serif` で出す。
- 見本はフォントを持たない。端末にはんなり明朝があれば `local()` で使い、なければ `--f-serif` で出す。

| 役割 | 大きさ | 行の高さ |
| --- | --- | --- |
| 本文 | 16px | 1.8 |
| カードの説明 | 15px | 1.7 |
| ボタン | 15px | 1.4 |
| 補足、標準の値 | 13px | 1.7 |
| コマンドの行 | 14px | 1.7 |
| 見出し | 24px、明朝 | 1.45 |
| 入口の題 | 30px、明朝 | 1.4 |
| 次に直す1点 | 22px、明朝 | 1.45 |
| 読む画面の歌 | `clamp(18px, min(6vw, 3.6svh), 26px)`、明朝 | 1.6 |

- 13px より小さい文字を使わない。例外は帯の名前の 12.5px だけである。
- 数値は `font-variant-numeric: tabular-nums` にする。残り秒数の桁が動かないようにするためである。

## 4. 余白と幅

- 1列の画面にする。幅は最大 `34rem` で中央に置く。パソコン用の別の形は作らない。
- 左右の余白は 16px、カードの内側は 12〜16px、ブロックの間は 16px にする。読む画面だけ 10px に詰める。
- 角の丸みは、ボタン 10px、カード 12px、入口の一覧 14px、帯 4px にする。
- 高さは `100svh` を基準にする。`100vh` はスマホのアドレスバーの分だけ切れるので使わない。
- 固定の位置に置く部品を作らない。`position: fixed` は使わない。

保証する範囲：

| 幅×高さ | 例 | 条件 |
| --- | --- | --- |
| 360×560 以上 | 小さいスマホ | 横スクロールなし。録音の画面が1画面に収まる |
| 393×659 | iPhone 15 Pro の Safari の見える範囲（`100svh` の仮定） | 入口と聞く画面も1画面に収まる |
| 幅 320px | 古い小型機 | 横スクロールなし。縦のスクロールは許す |

## 5. ボタン

| 種類 | クラス（見本） | 見た目 | 使う所 |
| --- | --- | --- | --- |
| 塗り | `btn btn--fill` | 朱の塗り、太字 | その画面で一番押してほしい操作。1つだけ |
| 線 | `btn` | `--ink` の線 | 再生など、その場の操作 |
| 弱い線 | `btn btn--line` | `--rule` の線、地は透明 | 別の道へ進む操作 |

- 押せる所は高さ 44px 以上にする。通常のボタンは 48px である。
- 移動は `<a href>`、その場の操作は `<button>` にする。JS がなくても移動できるようにするためである。
- 塗りのボタンは、親指に近い下側に置く。
- 再生と停止の印は SVG にする。文字の ▶ は端末で形が変わることがある。
- 2択の切り替えは `aria-pressed` で表し、選んでいる方を太字と 2px の線にする。塗りのボタンより目立たせない。
- 無効のボタンは `disabled` にして、理由が分かる場所に置く。

## 6. カードと行

- カードは `--card` の面に `--rule` の線で、影を付けない。
- カードの中の項目は `--rule-2` の線で区切る。
- 優先度は「優先 高」「優先 中」「優先 低」の文字で出す。高だけを `--shu-deep` にする。
- 次に直す1点のカードだけ、線を `--ink` にする。

## 7. 帯と歌詞

### 帯

- 帯は B1、C1、C2 で同じ部品にする。見本の `buildBand` と `paintBand` に当たる。
- 区間は配列で持ち、数を4に固定しない。序歌は下の句を2回読むので、形が変わる。
- 区間の幅は秒数に比例させる。
- 帯は1本にする。帯の中の文字は2行で、1行目に区間の名前、2行目に標準の秒数を数字だけで置く。左から 5、3、1、6 と並び、5・3・1・6 の方式がそのまま読める。単位の「秒」は付けない。「間」の区間は 360px で約 20px の幅しかなく、「1秒」は切れる。
- 帯の要素に `aria-label` を付け、「下の句 5秒、余韻 3秒、間 1秒、上の句 6秒」のように単位まで読ませる。
- 今の区間には 2px の線を付ける。進んだ分は区間の色で左から埋める。
- 時間は標準の 5・3・1・6 で進める。お手本の音とはずれてよい。

```ts
type Segment = { key: 'shimo' | 'yoin' | 'ma' | 'kami'; name: string; sec: number; label: string };
```

`label` は画面の表示で、「下の句（5秒程度）」「余韻（3.0秒）」「間（1.0秒）」「上の句（6秒程度）」である。

### 歌詞と帯をまとめた枠

上から順に、帯、今の区間の名前と残り秒数、歌詞の面を置く。枠の地は今の区間の色で、残り時間に合わせて上から減る。歌詞の面の右に 44px の幅を空け、減っていく色が見えるようにする。

- 視線を歌詞に置いたまま、周りの色で区間が変わったことが分かる形である。
- 残り秒数は 0.1 秒の単位で出す。
- 歌の縦書きは `writing-mode: vertical-rl` にする。
- 行に `white-space: nowrap` を付ける。付けないと、iOS の Safari が flex の中の縦書きを1字ずつの列に崩す。Mac の Chrome では再現しない（2026-11-03 にシミュレーターで確認）。
- 下の句と上の句の間は `0.7em` 空ける。
- 伸ばす印は最初から `--shu` にする。
- 読み終えた文字を `--shu` にするのは C3 からである。C3 までは文字を進めない。文字数で等分すると誤った手本になり、表に時刻の列がまだないからである。見本の文字の進みは仮の重みで動いている。
- お手本を聞く画面（C1）で文字を音に合わせて進めるのは、読手の確認が取れてからにする。

### 歌に出すもの

何を入れてよいかは `REVIEW.md` の表で決める。この節は、入れてよいものをどう出すかだけを決める。

| 内容 | 出し方 |
| --- | --- |
| 歌の本文 | 札の読みの表の本文の列から出す |
| 各歌の伸ばす箇所 | 出す。`--shu` の `ー` にする |
| 余韻の印 | 出す。下の句の最後の字のあとに置く。札の読みの表にまだ印の列がないので、印の形は列を足す作業で読み方一覧に合わせて決める。それまで部品は印なしで動く。見本には入れていない |
| ふりがな | `<ruby>` で出す。列の間は足りる。札の読みの表にまだ列がないので、部品は列が空でも動くようにする。見本には入れていない |
| 別の読み、注、発音の注意点 | 1首のページで、歌の下のカードに出す。読む画面には出さない。録音中に読む字を増やさない |
| 読み方の解説の文（トラップ、札ごとの注意点） | 教科書のページで出す。見本の文は仮の文である |

見本の 53番の全体、77番の下の句、29番の上の句の伸ばす箇所は、読手テキスト抜粋版 p.7、p.15、p.9 の画像と照らした。

## 8. コマンド風の入口

### 画面の形

読む流れ（聞く、読む）を除いて、どの内容も同じ順に並べる。読む流れは1画面に収めるので、5 と 6 がなく、歌の下にボタンを置く。

1. 上の帯：左に `/yomimasu`（入口へのリンク）、右に進み具合（`1 / 3 聞く` など）
2. 実行の行：`> /yomimasu 総論を学ぶ`
3. 読んだ行：`● Read 総論.md`
4. 本文。図解、音声、録音はカードで出す
5. 入力の行：`> /yomimasu ▮`
6. 「次は？」と次の操作

入口には 2 と 3 がなく、本文の代わりに題を置き、5 の下に一覧を置く。一覧の先頭だけを朱にして、「はじめての人はここから」を添える。自由入力の欄は作らない。

入れ替えると前の出力は消える。Claude Code のように積み重ねない。戻る操作で前の内容に戻すためである。

### 押したあとの動き

| 時刻 | 動き |
| --- | --- |
| 0ms | 押す。HTML の取得を始める。ほかのボタンを薄くする |
| 0〜280ms | 入力の行に文字を足す。字数によらず合計 280ms にする |
| 370ms まで | そのまま置く |
| 370ms | 本文を入れ替え、一番上へ移る。実行の行を出す |
| 480ms | `● Read` の行を出す |
| 590ms | 本文を出す |

- 合計は 1 秒未満にする。見本は Mac の Chrome で 602〜611ms だった。
- 取得が遅いときは入力の行のまま待つ。待っている表示を足さない。
- `prefers-reduced-motion: reduce` では動きを省き、すぐに入れ替える。
- URL を直接開いたとき、戻るで戻ったときは動きを出さない。
- 読む流れ（聞く、読む、確かめる）は道具のボタンなので、文字を打ち込まない。実行の行だけを出す。

### コマンドの対応

Web のボタンが打ち込む文字は、スキルでも同じ内容を返す（D2c）。ここを変えるときはスキルも変える。

| ボタン | 打ち込む文字（`/yomimasu` のあと） | 読んだ行 | URL の案 |
| --- | --- | --- | --- |
| まず1回読む | `まず1回読む` | なし | `/read/` |
| 総論を学ぶ | `総論を学ぶ` | `総論.md` | `/soron/` |
| トラップを知る | `トラップを知る` | `トラップ.md` | `/trap/` |
| 1首ずつ学ぶ | `1首ずつ学ぶ` | `一覧.md` | `/karuta/` |
| 1首のページ | `1首 53番` | `53番.md` | `/karuta/53/` |
| 序歌のページ | `1首 序歌` | `序歌.md` | `/karuta/joka/` |
| 最低限これだけ | `最低限これだけ` | `最低限これだけ.md` | `/saitei/` |
| 練習モード | `練習モード` | なし | `/practice/` |
| 読む | `読む 77番 29番` | なし | `/read/rec/?shimo=77&kami=29` |
| 結果を見る | `結果を見る` | なし | `/result/` |
| 例の録音で見る | `結果を見る` | なし | `/result/example/` |
| 前回と比べる | `前回と比べる` | なし | `/result/compare/` |

- `● Read` の名前は `content/` の実際のファイル名にする。ファイルがない画面では出さない。
- 録音のあとは `● 録音しました` を出す。実際に起きたことだけを書く。
- URL は英字にする。日本語の URL は共有すると長い文字列になる。Markdown の先頭に `slug` を足す形でよい。
- 組の指定は `?shimo=<札>&kami=<札>` にする。聞く画面と録音の画面で同じ形である。指定がなければ 77番と29番にする。
- 録音がないまま `/result/` を開いたら「まだ録音がありません。」と出し、まず1回読むへ案内する。録音は端末の中にしかないので、URL だけでは結果を開けない。

## 9. 録音の画面

見本の `/read/rec/` で動かせる。雛形の `recorder.tsx` の `View` を次の状態へ広げる。見本はマイクを開かないので、`starting` がない。

録音の結果は次の形で受け渡す。測定と再生はこの形だけを読む。

```ts
type Take = {
  pcm: Float32Array;
  sampleRate: number;
  readingStartSec: number; // 帯が動き始めた位置。合図の分を読み飛ばすために持つ
  assisted: boolean;
  pair: { shimo: CardId; kami: CardId };
};
```

| 状態 | マイク | 帯 | ボタン | 次へ |
| --- | --- | --- | --- | --- |
| `idle` | 閉じている | 0 で止まる | 読み始める、補助あり、補助を外す | 押すと `starting` |
| `starting` | 開いている途中 | 0 で止まる | やめる | 許可で `count`、拒否で `failed` |
| `count` | 録音中 | 0 で止まる | やめる | 3拍のあと `reading` |
| `reading` | 録音中 | 進む | やめる、読み終えた | 読み終えたで `heard`、25 秒で自動で `heard` |
| `heard` | 閉じる | 出さない | 自分の読み、お手本、読み直す、結果を見る | 結果を見るで結果 |
| `failed` | 閉じている | 止まる | もう一度試す、教科書へ戻る | |

決まり：

- 合図は 3、2、1 を 0.8 秒ずつ、枠の上に数字で出す。音は鳴らさない。録音に入るからである。
- 録音は合図の前から始める。マイクが開く遅れで読みの頭が切れないようにする。
- 測定と再生には、合図の間の音を渡さない。今の測定は録音全体の最も長い無音を間とするので、合図の間の物音や、読み終えたあとのボタンの音で値が大きくずれる。範囲は `Take` の `readingStartSec` から取り、前後の余白は測定の定義で決める。
- 帯の時計は `AudioContext.currentTime` から取る。`requestAnimationFrame` は描くためだけに使う。
- 録音中は右上に赤い丸、「録音中」、経過秒数を出す。色だけで伝えない。
- 「読み終えた」は上の句の区間から押せるようにする。早く押して短い録音になるのを防ぐ。
- 帯が終わっても 10 秒は録音を続ける。読むのが遅い人の最後を切らないためである。
- 「やめる」を押すと録音を捨てて `idle` へ戻る。
- 録音中に歌詞の位置を動かさない。ボタンの部分の高さを `min-height` で取っておく。見本では開始の前後で座標が同じだった。
- 録音中に別の画面を出さない。リンク、案内、音を足さない。お手本を鳴らさない。
- 持ち方の案内は出さない（ユーザーの判断）。
- 画面が隠れたらやめる扱いにして、マイクを閉じる。録音の画面を離れるときも同じである。
- 録音が終わったらすぐマイクを閉じる。そのあとに再生する。
- `stop` の直後の連打で録音が始まらないよう、雛形の `RESTART_GUARD_MS` を残す。
- 読み直しのときは、実行の行の代わりに1行だけ「直す1点：間を1.0秒にそろえる」の形で出す。行を足すと 360×560 に収まらない。
- 「例の録音で見る」の入口は、C9 ができてから出す。行き止まりを作らない。

補助を外したとき：

- 帯の進み、枠の色の減り、残り秒数を消す。C3 のあとは文字の進みも消す。
- 歌詞、録音中の表示、「読み終えた」は残す。
- 枠の見出しは「補助なし」にする。
- 結果と記録に補助の有無を残す。

録音の前の説明は、機能に合わせて事実だけを書く。C8 より前は「録音はこの端末の外へ送りません。」とだけ書き、「残ります」「あとから消せます」は C8 のあとに足す。

## 10. 録音のあと

### 確かめる（`heard`）

数値を先に見せない。「読めました。まず聴いてみましょう。」のあとに、自分の読みとお手本の再生を置く。塗りのボタンは「結果を見る」である。

### 結果（C5）

- 行の順は、下の句＋余韻、間、上の句、決まり字までの速さで固定する。
- 1行に、項目名、標準の値、測った値を出す。判定は、判定を出す項目（下の句＋余韻、間、決まり字までの速さ）だけに付ける。上の句には付けない。
- 間の標準の値の欄は「目安」と書き、幅で出す（例：「目安 0.9〜1.2秒」）。値は `docs/measure.md` から取り、ガイドとコードに別の値を書かない。出典の書き方は `REVIEW.md` に従う。
- 上の帯の右に、補助の有無を「補助あり」「補助なし」と出す。
- `Measurement` の型にない項目は行を作らない。決まり字までの速さと音量は、定義と型が入ってから足す。
- 余韻だけの秒数を出さない。
- 音量は行にせず、文の中で参考として出す。「今回の音量は -18 dB でした。参考の値で、端末と持ち方で変わります。」
- 「明瞭さは測っていません。お手本と聴き比べてください。」を必ず出す。
- 「録音は端末の外へ出ません。」を画面の下に出す。動画の段8でも映す。
- 例の録音のときは、先頭に「例の録音です」と出す。

### 次に直す1点（C7）

- カードは結果の行の下に1つだけ置く。
- 見出しは「次に直す1点」、大きな文字は直す内容、その下に理由と直し方を置く。
- 全項目が幅の中なら「今回はありません」として、補助を外して読むことを勧める。
- 測れなかった項目は、1点に選ばない。全部測れなければカードを出さない。
- 「Claude が選びました」と書かない。
- 関わる教科書のページへのリンクを「次は？」に置く。

## 11. 失敗の文言

| 場面 | 表示 | 次の操作 |
| --- | --- | --- |
| マイクを許可しない | マイクを使えませんでした。ブラウザーの設定でマイクを許可すると、読んで測れます。教科書とお手本はこのまま使えます。 | もう一度試す。C9 のあとは例の録音で見る |
| 録音を始められない | 録音を始められませんでした。ページを開き直してください。 | もう一度試す |
| 声が小さくて測れない | 声を聞き取れず、測れませんでした。読み直すか、静かな場所で試してください。 | 読み直す |
| 切れ目が見つからない | 読みの切れ目が見つからず、測れませんでした。間を空けて読み直してください。 | 読み直す |
| お手本を読み込めない | お手本を読み込めませんでした。通信を確かめて、もう一度押してください。 | もう一度押す |
| ページがない | このページはありません。 | 入口へ戻る |

値を推測で埋めない。測れない項目は「測れませんでした」と出す。

## 12. 言葉

### 使う言葉

| 使う | 使わない | 理由 |
| --- | --- | --- |
| 読み | 読唱（画面の中で） | 相手に身近な言い方にする |
| 間 | 間合い、ポーズ | 動画と結果で同じ語にする |
| 1組 | ペア、セット | 前の札の下の句から次の札の上の句までを指す |
| お手本 | 正解、見本 | |
| 次に直す1点 | アドバイス、AI の提案 | |
| 補助 | ガイド、カラオケ | |
| 冊子、フルバージョン | 完全版 | 「完全版」は内部の言い方である |
| 測れませんでした | エラー、失敗 | |

数は算用数字で書く（1組、1回、100首）。「ブラウザー」と伸ばす。

### 判定の語

判定の幅は、測定の定義と同じ場所で決める。

| 向き | 語 |
| --- | --- |
| 幅の中 | ちょうどよい |
| 長さの項目が長い、短い | ちょっと長い、ちょっと短い |
| 速さの項目が速い、遅い | ちょっと速い、ちょっと遅い |

大きく外れたときの語は作らない。

### ユーザーが直した文

次の文はそのまま使う。言い換えない。

- 入口：「読みます」と言うために。／すべての人に、読みを身近に。（1行で出す）
- 最低限：読む札を間違えない／読み札の取り扱いを間違えて、同じ札を2回読んだり、読むべき札をスキップしたりしないよう、気をつけましょう。
- 1首：なげけとて（86番）と3字目で分かれるので、なげき まで明瞭に読みます。
- 結果：今回の音量は -18 dB でした。（数値は測った値に替える）

## 13. 出さないもの

- 「考え中」「考えました」と、それに見える表示（回る印、点の点滅）。
- 総合点、順位、星、達成率。
- 読手、メモの著者、選手の実名。お手本は「A級公認読手のお手本」と書く。
- 読手テキストの文、図、ページの画像。
- 機械読みの製品名。
- 協会の公認や Anthropic の製品に見える表示。入口の下に次の文を置く。「個人の制作物です。協会の公認ではなく、Anthropic の製品でもありません。Claude Code で作りました。」
- 有料の機能、広告、登録の案内。
- 持ち方の案内。
