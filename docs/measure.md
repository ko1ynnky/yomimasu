# 測定の定義

Web とスキルは、この定義に合わせて `.claude/skills/yomimasu/scripts/measure.ts` を共有する。

状態は雛形の仮の定義である。合成音でしか確かめていない。実際の読みに合わせた定義は、手元の録音で確かめてから決める。

## 対象

1組の録音を入力にする。1組は、前の札の下の句で始まり、余韻と間を挟んで、次の札の上の句で終わる。

序歌はこの定義の対象外である。下の句を2回読むので、扱いは別に決める。

## 声の区間

1. 80Hz より低い音を除く。
2. 20ms の窓を 10ms ずつ動かして、音量（dB）を求める。
3. 音量の下位5%を背景の音、上位5%を声の大きさとする。
4. 背景の音から声の大きさまでの45%を超えたら声の始まり、30%を下回ったら声の終わりとする。
5. 0.25 秒未満の切れ目はつなぐ。0.1 秒未満の声は捨てる。

## 項目

いずれも単位は秒で、0.01 秒に丸める。「最も長い無音」は、声の区間の間の無音のうち最も長いものを指す。

| 項目 | 開始点 | 終了点 |
| --- | --- | --- |
| 下の句＋余韻の長さ | 最初の声の始まり | 最も長い無音の直前の声の終わり |
| 間 | 最も長い無音の始まり | 最も長い無音の終わり |
| 上の句の長さ | 最も長い無音の直後の声の始まり | 最後の声の終わり |

余韻だけの長さは測らない。

## 測れない条件

値を作らず、状態だけを返す。

| 状態 | 条件 |
| --- | --- |
| `too-quiet` | 声の大きさと背景の音の差が 15dB 未満である |
| `no-gap` | 声の区間が2つ未満である |
