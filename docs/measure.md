# 測定の定義

Web とスキルは、この定義に合わせて `.claude/skills/yomimasu/scripts/measure.ts` を共有する。選べる定義と値（判定の幅の目安を含む）は `.claude/skills/yomimasu/scripts/definition.ts` に置く。この文書では、その値をデータの名前（例：`window.lookbackSec`）で指し、今の値は末尾の「定義のデータ」の表に書く。表の行がデータと一致することは `test/measure/definition.test.ts` が確かめる。候補ごとに固定の値（窓の長さ、閾値の比など）は `measure.ts` にあり、下の手順に書く。

状態：2026-11-05 にユーザーが決めた。録音で確かめた結果は `npm run eval:real` で出す。人が付けた正解データとはまだ比べていない。

## 対象

1組の録音を `measure` で測る。1組は、前の札の下の句で始まり、余韻と間を挟んで、次の札の上の句で終わる。

序歌は、下の句を2回読んでから1首目の上の句へ進むので、2つに分けて測る。

- 序歌の上の句は、1つだけで `measureKami` で測る。上の句の長さと声の大きさだけを返す。
- 序歌の下の句（1回分）は、ほかの札の上の句と組にして、ふつうの1組と同じく `measure` で測る。

どちらで測るかは、呼ぶ側（Web とスキル）が組で決める。

## 測る範囲

- 読み始めの位置（`Take` の `readingStartSec`）の `window.lookbackSec` 秒前から、録音の終わりまでを測る。それより前の合図の間の音は測らない。
- スキルに渡す音声ファイルと Web の例の録音は、合図の間の音を含まないので、`readingStartSec` を 0 にして頭から測る。
- 読み始めより前から見るのは、帯が動くのと同時か少し前に出た声の頭を切らないためである。この範囲に入った合図の終わりの短い物音は、手順4で物音として除く。
- 測る範囲の最初で声が続いていれば、下の句（序歌は上の句）の始まりが分からないので、その項目を測れないとする。録音の最後で声が続いていれば、上の句を測れないとする。

## 声の区間

`voicedSpan.method` の定義で決める。決めたのは `voiced-level-20` で、どの無音が間かを声の周期性で見つけ、声の終わりは音量で決める。

1. 80 Hz より低い音を除き、20 ms の窓を 10 ms ずつ動かして音量（dB）を求める。
2. 音量の下位5%を背景の音、上位5%を声の大きさとする。差が `voicedSpan.minRangeDb` 未満なら測らない。
3. 8 kHz 前後に間引き、200 Hz より低い音を除き、30 ms の窓で 60〜500 Hz の周期の強さ（自己相関の最大）を求める。0.8 以上を声とする。
4. 0.25 秒未満の切れ目をつなぐ。つないだまとまりのうち、声だった長さの合計が `noise.minPhraseSec` 未満のものは物音として除く。
5. 残ったまとまりの間の無音のうち、最も長いものを間とする。周期性のまとまりが2つ未満なら、理由によらず、下の `floor-45-30` で声の区間を決める。背景に人の声があると、周期性では間を見つけられないからである。`floor-45-30` でもまとまりが2つ未満なら測らない。上の句だけを測るときは、この手順と手順6を使わない（下の「上の句だけを測るとき」）。
6. 下の句の声の終わり：
   1. 間の直前のまとまりの周期の終わりから、1.5〜0.2 秒前の音量の上位10%を、最後の音の大きさとする。
   2. 間の背景の大きさは、間の両端の 0.05 秒を除いた音量の中央値とする。
   3. 閾値は、最後の音の大きさより 20 dB 低い値とする。ただし、間の背景より 6 dB 高い値を下限にする。
   4. 周期の終わりの 0.4 秒後か、次のまとまりの周期の始まりの 0.05 秒前の、早い方から前へたどる。閾値以上の音量の最後のフレームの次を、声の終わりとする。
   5. 周期の終わりの 0.3 秒前まで閾値以上のフレームがなければ、周期の終わりの 0.29 秒前を声の終わりとする。背景が声の高さまで持ち上がったときに、周期の終わりから離れすぎないためである。
7. 声の始まり（下の句、上の句）：周期の始まりから、音量が間の背景より 6 dB 高い間、0.2 秒まで前へ戻る。上の句だけを測るときは、間の背景の代わりに手順2の背景の音を使う。
8. 上の句の終わり：最後のまとまりの周期の終わり。

上の句だけを測るとき（`measureKami`）は、手順1〜4のあと、周期性のまとまりの最初の始まりを手順7で前へ戻した所を始まり、最後のまとまりの周期の終わりを終わりとする。周期性のまとまりが1つもなければ、下の `floor-45-30` で決める。それでもまとまりが1つもなければ測らない。

データの1行で、ほかの候補に替えられる。どちらも手順 1、2、4、5 は同じで、声の区間を音量だけで決める。上の句だけを測るときは、最初のまとまりの始まりから最後のまとまりの終わりまでを上の句とする。

| 候補 | 声の始まり | 声の終わり |
| --- | --- | --- |
| `floor-45-30` | 背景の音から声の大きさまでの45%を超えた所 | 30%を下回った所 |
| `speech-20-15` | 声の大きさから 20 dB 下を超えた所 | 声の大きさから 15 dB 下を下回った所 |

`speech-20-15` の閾値は、どちらも背景の音より 6 dB 高い所を下限にする。

## 項目

秒は 0.01 秒に丸める。

| 項目 | 開始点 | 終了点 | 単位 | 測れない条件 | 出すか |
| --- | --- | --- | --- | --- | --- |
| 下の句＋余韻の長さ | 下の句の声の始まり | 間の直前の声の終わり | 秒 | `too-quiet`、`no-gap`、`cut-off` | 出す |
| 間 | 間の直前の声の終わり | 上の句の声の始まり | 秒 | `too-quiet`、`no-gap` | 出す |
| 上の句の長さ | 上の句の声の始まり | 上の句の終わり | 秒 | `too-quiet`、`no-gap`、`cut-off` | 出す |
| 余韻 | 下の句の最後の音の子音の始まり | 間の直前の声の終わり | 秒 | | 出さない |
| 決まり字までの速さ | 上の句の声の始まり | 初句の最後の音の始まり。開始点からの秒を初句の字数－1で割る | 秒／字 | | 出さない |
| 声の大きさ（音量の参考値） | | | dB | `too-quiet`、`auto-gain` | `level` のとおり |

- 余韻は、最後の音の子音の始まりから数える（`yoin.countFrom`）。録音だけから最後の音の始まりを取る方法では、誤差が目標（`errorTargets.yoin`）に届かないので出さない。お手本の区切りを写す方法でも、90%点が目標を超える。出すには、目標に届く取り方が要るので、型で `yoin.output: false` に留めている。
- 決まり字までの速さは、お手本の録音に付けた区切りを利用者の録音へ写して測る（`pace.per`）。お手本の区切りの値は読手の測定値なので、読手の確認が取れるまでリポジトリに入れない。値がないので出さず、型で `pace.output: false` に留めている。
- 声の大きさは、測る範囲のフレームの音量の上位5%を 1 dB の単位で出す。録音の振れ幅の最大を 0 dB とする。良し悪しは判定しない。自動の音量調整がかかると、入力の大きさによらず同じような値になる。`level` が `when-auto-gain-off` のときは、録音の設定（`autoGainControl: false`）で調整が切れていると確かめた録音だけで出す。設定の値を信じられない端末では、呼ぶ側が `autoGainControl: false` を渡さない。iPhone は、実機で確かめるまで渡さない。上の句だけを測るときに声のまとまりが1つもなければ、上位5%の音量は物音の大きさなので、声の大きさも出さない。
- 誤差の目標（`errorTargets`）に届かない項目は、画面に出さない。

## 判定の幅の目安

- 幅は `ranges` にあり、間、下の句＋余韻、上の句の3つに付ける。どの幅も目安で、画面とスキルの答えでは「目安」と書く。出典は書かない。
- 幅の中を「ちょうどよい」とする。幅は両端を含む。幅のない項目（声の大きさなど）には判定を付けない。
- 画面とスキルの答えでは、秒を 0.1 秒に四捨五入して出す（`measure.ts` の `tenthSec`）。判定も同じ 0.1 秒の値で決める（`rangePlacement`）。測った値（`Measurement`）は 0.01 秒のまま持つ。
- 序歌の上の句にも、上の句の幅を当てる。

## 測れない条件

値を作らず、理由だけを返す。

| 理由 | 条件 | 当てる項目 |
| --- | --- | --- |
| `too-quiet` | 声の大きさと背景の音の差が `voicedSpan.minRangeDb` 未満である。録音が窓より短い。上の句だけを測るときに、物音を除いたまとまりが1つもない | 秒の項目と声の大きさ |
| `no-gap` | 物音を除いたまとまりが2つ未満である | 1組の秒の3項目 |
| `cut-off` | 測る範囲の最初か録音の最後で、声が切れている | 下の句＋余韻（最初）、上の句（最初は上の句だけを測るとき、最後はどちらも） |
| `auto-gain` | 自動の音量調整が切れていると確かめられない | 声の大きさ |

## 録音で確かめる

```bash
npm run eval:real -- <一覧の JSON> [--method <声の区間の候補>]
```

- 録音と基準の値は、リポジトリの外の一覧（JSON）で渡す。一覧の形は `scripts/measure/eval-real.ts` の頭にある。録音はアプリの録音と同じく、読み始めの前に合図の時間を含めておく。
- 組ごとの値は出さず、誤差の統計と、`errorTargets` に対する合否だけを出す。
- 合図の間に声と物音を、読み終えたあとに声、物音、ボタンの音を足した録音も測り、値が 0.01 秒より動かないことを確かめる。
