# 札の読みの表

Web とスキルが共通に使うための、序歌と100首の表の説明である。表の本体は `.claude/skills/yomimasu/assets/cards.json`、型と計算は同じスキルの `scripts/cards.ts` にある。今この表を読むのは `scripts/cards/`、テスト、画面の歌詞の部品（`site/client/lyrics.ts`）と録音の画面の決まり字（`site/client/recorder.tsx`）で、測定はまだ読んでいない。歌詞の部品は `yoin` の列の位置に余韻の印を置き、`sound` からふりがなを振る。`sound` には一覧のふりがなの「ー」と注の字が入っている。`furigana`、`notes`、`alternatives` の列をそのまま読む画面はまだない。

## 持っているもの

| 項目 | 内容 | どこから来るか |
| --- | --- | --- |
| `no` | 札の番号。0 が序歌 | 公開の本文データ |
| `phrases[].text`、`kana` | 句ごとの本文と歴史的仮名遣いの仮名 | 公開の本文データ。序歌だけ手で入れた |
| `phrases[].parts` | 漢字のかたまりと読みの組 | 公開データの本文と仮名を重ねて作る。一覧のふりがなは使わない |
| `phrases[].sound` | 読むときの音を今の仮名で書いた列。長音は読み方一覧の表記に合わせて「ー」で書く | 仮名に読み替えの規則を当て、読み方一覧のふりがなの「ー」と注の字を当てて作る |
| `phrases[].diffs` | 仮名と発音が違う箇所。仮名の位置、元の字、読み替えた字、規則（`rule`）を持つ。一覧の「ー」と注を当てた箇所の `rule` は「一覧のふりがな」か「一覧の注」である | 同上 |
| `kimariji` | 決まり字。仮名の形と発音の形。序歌は `null` | 発音から計算する |
| `ruleStretches` | 規則から出る伸ばす位置 | 計算する。四句の途中は規則から出ないので入らない |
| `stretches` | 札ごとの伸ばす箇所 | 読手テキスト抜粋版の読み方一覧の本文の列の印 |
| `marked` | 本文に「ー」を置いた形 | `stretches` から計算する |
| `furigana` | 読み方一覧のふりがな。句の番号、仮名の位置と字数、読みを持つ | 読み方一覧の本文の右の近い列 |
| `notes` | 括弧で囲んだふりがな（注）。形は `furigana` と同じで、括弧は持たない | 同上 |
| `alternatives` | 別の読み。句の範囲、一覧の字に印を置いた形、伸ばす位置を持つ | 読み方一覧の本文の右の遠い列 |
| `yoin` | 余韻の印の位置 | 読み方一覧の下の句の後ろの図形 |
| `origin` | 本文の修正、発音の例外、伸ばす箇所のページ、上の4列のページ | 札ごとの由来 |

伸ばす位置の `after` は、句の頭から数えた仮名の字数である。発音の位置へは `soundOffset`、逆は `kanaOffset` で移す。字数が変わる読み替えは「けふ」と「てふ」である。測定で使うときは、対応づけの定義を `docs/measure.md` に書く。

字数の変わらない長音の綴り（「あふ」「いふ」「がふ」）は、1字ずつの読み替えとして `diffs` に持つ（「い」→「ゆ」、「ふ」→「ー」）。一覧では「いふ」の「い」に「ゆ」、「ふ」に「ー」のように字ごとにふりがなが付き、44番の「逢ふ」のように漢字と仮名の部分にまたがる所もあるからである。字数の変わる「けふ」と「てふ」は、仮名2字で1つの読み替えにする。`soundOffset` はその途中へは移せず、`kanaOffset` はその途中を返さない。

## ふりがな、注、別の読み、余韻の印の形

4列とも、位置は伸ばす箇所と同じく句の仮名の字数で持つ。本文の漢字の列は一覧の表記と202行のうち116行が違い、一覧では漢字の所が表では仮名だったり、その逆だったりする（81番の「ありあけ」は一覧が仮名で表が漢字である）。ふりがなを本文の漢字に結びつけると置き場がなくなる札が出るが、仮名の位置ならどちらの表記でも同じ所を指せる。画面でふりがなを置く漢字は、`parts` と仮名の位置を重ねて決める。

- `furigana` と `notes` は `{ phrase, at, length, reading }` の配列である。`reading` は一覧の字のままで、長音は「ー」、語中の「は」は「わ」のように、今の発音で書かれている。
- ふりがな1つは、一覧の本文の漢字のかたまり1つか、仮名1字に掛かる分である。句の切れ目と注の括弧でも分ける。「けふ」と「てふ」は読みを字ごとに分けられないので、仮名2字で1つにする。この分け方で707か所になる。
- 注は括弧の中の字だけを持つ。10首に12か所ある。
- `alternatives` は `{ phrases: [最初の句, 最後の句], marked, stretches }` の配列である。別の読みは行の頭から始まり、句の終わりで終わる。`stretches` はその句の範囲を別の読みで読むときの伸ばす位置で、範囲の外は札の `stretches` のとおりに伸ばす。`marked` は一覧の別の読みの字で、句の途中の短い線と句の終わりの長い線を、どちらも「ー」にした。
- 99番の別の読みで「思ふ」の後ろにある線は、ふりがなの長音である（2026-11-04 にユーザーが冊子で確かめた）。一覧は、この読みの伸ばしの印を別に書いていない。伸ばす位置は、講習資料 s.31 が「世を思ふ」の後で伸ばす読みとして示すのに合わせ、「思ふ」の後ろ（四句の5字目の後ろ）とした。
- `yoin` は `stretches` と同じ `{ phrase, after }` で、余韻の印の位置を指す。一覧では序歌と100首のすべての下の句の後ろに、同じ形の図形が1つずつある。札で違わないので値は全札で下の句の終わりだが、伸ばす箇所と同じ処理で画面に置けるよう、札ごとの列にした。
- 4列の由来は札ごとに `origin.notation` に残す。`source` は値を入れてよい根拠の版（完全版、`booklet`）、`readFrom` は機械で読み取った版（抜粋版、`list`）、`page` は両版で同じページの番号である。

採らなかった案：

- ふりがなを本文の漢字の位置で持つ案。表の本文と一覧の表記が違う札で置けない。
- 一覧のふりがなを字の間隔で塊に分け、塊ごとに持つ案。隣の語のふりがなとつながったり（11番の「原」と「八十島」は句をまたいで1つの塊になる）、1語のふりがなが割れたり（47番の「八重葎」）して、件数が印刷の間隔で揺れる。
- 表の `parts` の切れ目で分ける案。公開データと一覧の2つの書き方が混ざり、一覧のどのふりがなかが分からなくなる。
- 注を括弧つきで `furigana` に混ぜる案。注だけを取り出せず、括弧が表に入る。
- 別の読みを字の列だけで持つ案。伸ばす位置を測定で使えない。逆に位置だけで持つと、99番の形や「を」の書き方が一覧と変わる。
- 余韻の印を表全体で1つの決まりとして持つ案。版が変わって札ごとに違ったときに、表の形から変えることになる。

## 許可の範囲

許可の範囲は `REVIEW.md` の「資料の範囲」で決め、資料の名前と版は `NOTICE.md` の「協会の資料」にある。伸ばす箇所の基準は抜粋版の令和7年4月1日改訂版である。

ふりがな、注、別の読み、余韻の印は、`REVIEW.md` の表で完全版の内容として入れてよい項目である。2026-11-04 に、抜粋版の文字のデータから機械で読み取った値を、完全版のスキャンの読み方一覧 p.5-15 と目で照らした。一致を目で確かめたのは、ふりがな707か所のうち706か所と、注12か所、別の読み10行、余韻の印101札である。残る1か所は33番の下の句のふりがな「ごころ」で、p.13 では濁点が判別できず、完全版 p.27 が同じ四句を「しづごころ」と印刷していることで確かめた。2026-11-04 に、ユーザーが冊子の実物でも「ご」と確かめた。抜粋版だけにある値と、両版で違う値は見つからなかった。発音の注意点はまだ入れていない。

発音の列は、歴史的仮名遣いの一般の読み替えの規則を仮名に当てて作る。規則だけでは決まらない語の切れ目が23か所あり、一覧のふりがなと比べて見つけて、`scripts/cards/corrections.ts` に足した。この23か所には、読み替えを示すふりがなが付いていない。逆に「を」のほかの読み替えた字には、どれもふりがなか注が掛かる。ふりがなと注の読みは、掛かる範囲ごとに発音の列と同じ字である。

発音の列は、読み方一覧の表記に合わせる（2026-11-04 のユーザーの判断）。長音の綴りの規則は「ゆー」「ちょー」のように「ー」で書く。規則の読み替えのあと、一覧のふりがなが「ー」の字と、注の字を当てる（`scripts/cards/sound.ts` の `withListNotation`）。お段に続く「ふ」のように、規則では「語中のハ行」で「う」になる長音は、ここで「ー」になる。字数は変えないので、伸ばす位置とふりがなの位置は当てる前と同じである。2026-11-04 の main（8981cc5）の表から変わったのは31句で、長音の綴りの規則を「ー」にしたのが13句、一覧のふりがなの「ー」を当てたのが14句、一覧の注の（お）を当てたのが4句である。注のある残りの8か所は、規則の読み替えがすでに注の字なので変わらない（16番の「生ふる」の注は（う）で、発音は「おうる」）。札ごとの例外の表は持たない。

本文は公開の本文データを使い、4札は一覧の形に合わせた。33番、44番、74番と序歌である。札の `origin` に残す。序歌は競技かるたで読む形で、四句の頭が一般の形の「今は」と違う。違いは[ウィキペディアの「難波津の歌」](https://ja.wikipedia.org/wiki/難波津の歌)で確かめた。

規則のうち、下の句の終わりを三字前にする語尾は、抜粋版 p.4 の決まりにある形である。一覧の印から逆算していない。

## 作り方

資料はリポジトリの外に置く。`build.ts` は版のハッシュを確かめてから読む。

| 資料 | 場所 | SHA-256 |
| --- | --- | --- |
| 歌の本文 | [nyoronjp/Ogura_Hyakunin_Isshu.csv](https://github.com/nyoronjp/Ogura_Hyakunin_Isshu.csv) のコミット `42cfd44` の `小倉百人一首.csv` | `f99510dcd54838a2be3bc8cd2e96d2063d799705248615906a939b4dcaeaf34b` |
| 読み方一覧 | [協会の読手のページ](https://www.karuta.or.jp/karuta/reading/)の抜粋版 PDF | `ae619e9a8a75e1702014f0c41d53b7ae8c32d3015926985090ad8a4c6c182a77` |

完全版はスキャンの画像を目で照らすのに使い、`build.ts` は読まない。照らしたスキャンの SHA-256 は `f650be9b4b4bb73e1cdca4143d74faa9025c080c1c023c9baf15e5a40271d695` である。

```bash
node scripts/cards/build.ts --csv <小倉百人一首.csv> --pdf <抜粋版.pdf>
```

実行には poppler の `pdftotext` と `pdftohtml` が要る。CI では使わない。

`scripts/cards/list.ts` が語の座標から、本文の列、ふりがなの列、本文の右の遠い列（別の読み）を分ける。余韻の印は文字のデータに出ない画像なので、`pdftohtml` で画像の位置を読み、下の句の最後の字のすぐ下にあるかを見る。序歌と100首が1枚ずつそろわなければ止まる。`build.ts` は発音、印、4列を一覧と比べ、すべて合うときだけ表を書く。

本文データには誤りがあるので、`scripts/cards/corrections.ts` で直し、札の `origin.text.fixes` に残す。上の3札のほかに、データの漢字の列の誤り7か所、伸ばす箇所を示すために仮名へ開いた3か所、語の扱いのために書き方を変えた1か所がある。

## 検算

### CI で確かめること

`test/cards/` のテストである。資料がなくても動く。

- 101枚そろい、どの札も5句で、字数は 5、7、5、7、7 に字余り1字までである。
- 字余りは32首、初句が6字の札は8首、1音目が母音の札は28首である。
- 決まり字は一意で、字数の内訳は 7、42、37、6、2、6 首である。6字決まりは大山札の6首と一致する。
- 札ごとの伸ばす箇所は、規則の位置に四句の途中の1か所を足したものである。例外は63番だけである。
- 印は100首で694か所、上の句394、下の句300である。下の句の終わりが三字前の札は11首である。
- 発音の列は、仮名に `diffs` を当てたものと一致し、歴史的仮名遣いの字を含まない。
- `diffs` は、規則の読み替えに一覧のふりがなの「ー」と注の字を当てたものと一致する。一覧のふりがなが「ー」の所は発音も「ー」で、発音の「ー」はそこにしかない。注の所は注の字である。どちらもない所は規則の読み替えのとおりである。この検算は書き方の違いを揃えずに比べる。
- ふりがなは707か所でどの札にもある。注は10首に12か所、別の読みは10首に1つずつある。余韻の印は101札のすべてにあり、下の句の終わりを指す。
- ふりがなと注は句の中で重ならず、発音の位置へ移せ、掛かる範囲の発音の列と同じ字である。「を」のほかの読み替えた字には、どれもふりがなか注が掛かる。
- 大山札の別の読みは二句の途中で1か所多く伸ばし、ほかの4首の別の読みは四句の途中の伸ばしを後ろへずらす。
- 81番の下の句と45番の上の句は、完全版のスキャンと1字ずつ照らした値と一致する。
- どの札にも由来があり、札と句に決めた項目のほかを持たない。

### 公開の一覧と照らす手順

```bash
node scripts/cards/build.ts --csv <小倉百人一首.csv> --pdf <抜粋版.pdf> --check
```

一覧の本文の仮名、ふりがなをかぶせた読み、伸ばしの印、ふりがな、注、別の読み、余韻の印を表と比べ、資料から作り直した表とも比べる。合わない札の番号と件数だけを出し、一覧の本文は出力しない。不一致があると exit 1 で終わる。

比べる前に書き方の違いを揃える。長音の書き方、「を」と「お」、「ぢ」と「じ」、「づ」と「ず」は同じ音として扱う。

### 目で読み直す手順

`--check` は一覧の文字データを読むので、印刷の見え方と文字データが違っても気づけない。一覧のページの画像だけから本文の列と印を書き起こし、機械の読み取りと比べる。

```bash
node scripts/cards/build.ts --csv <小倉百人一首.csv> --pdf <抜粋版.pdf> --reread <書き起こし.tsv>
```

書き起こしは1行が「番号、上の句、下の句」のタブ区切りで、リポジトリに置かない。2026-11-03 に、表を作ったのとは別のモデルが表を見ずに画像だけで書き起こした。序歌と100首の202行、印701か所で差は0行だった。

ふりがな、注、別の読み、余韻の印は、`--reread` では見ない。2026-11-04 に、機械の読み取りを札ごとに書き出し、完全版のスキャンのページの画像と1か所ずつ照らした。ふりがなは707か所のうち706か所、注12か所、別の読み10行、余韻の印101札が合った。残る1か所は下の「33番」の項目のとおり、p.27 の印刷と冊子の実物で確かめた。81番の下の句と45番の上の句は、本文の列の字と印も1字ずつ照らし、ユーザーも冊子の実物と照らした（2026-11-04）。

## 機械の検算で足りない箇所

- 四句の途中の100か所は規則から出ない。CI は位置が1か所あることしか見ない。値は `--check` と目の読み直しで確かめた。
- 規則の位置のうち、句の字数から出るのは494か所である。上の句の終わりの手前の100か所は、札の番号を一覧の印で決めたので、一覧との比較は独立の検算にならない。二字前の25首のテストも同じである。
- お手本の音声とは照らしていない。
- 「を」は発音の列ですべて「お」にした。これは位置の対応づけのための扱いで、読み分けの判断ではない。教科書の説明には使わない。
- 発音の比較は上の書き方の違いを揃えて行うので、その違いは検算に出ない。発音の列の「ー」と注の字は、CI のテストが表の `furigana` と `notes` の列と揃えずに比べる。その2列が一覧と合うことは `--check` で確かめる。
- 本文の漢字の列は公開の本文データのままで、一覧の表記とは202行のうち116行が違う。読みが同じことだけを確かめた。
- 序歌の本文は手で入れた。公開の本文データとは照合できない。
- 決まり字は発音から計算した。一意であることと字数の内訳を確かめただけで、札ごとに別の資料と比べてはいない。
- ふりがなの分け方は上の決まりで決めたもので、印刷のふりがなの区切りそのものではない。707か所はこの決まりでの数である。
- 33番の下の句のふりがな「ごころ」は、完全版の読み方一覧（p.13）のスキャンでは「ご」の濁点が判別できなかった。完全版 p.27 が同じ四句を「しづごころ」と印刷しているので、その形を根拠に入れた。抜粋版では文字のデータも印刷の画像も「ご」である。2026-11-04 に、ユーザーが冊子の実物の p.13 で「ご」と確かめた。
- 99番の別の読みの伸ばす位置は、一覧に印がないので、講習資料 s.31 の説明による。
- 余韻の印は位置だけを持ち、図形の長さや太さは持たない。どの札も同じ画像である。
- 完全版のスキャンとの照合は目で行った。スキャンを機械で読み取って比べてはいない。
