# 札の読みの表

Web とスキルが共通に使うための、序歌と100首の表の説明である。表の本体は `.claude/skills/yomimasu/assets/cards.json`、型と計算は同じスキルの `scripts/cards.ts` にある。今この表を読むのは `scripts/cards/` とテストだけで、画面と測定はまだ読んでいない。

## 持っているもの

| 項目 | 内容 | どこから来るか |
| --- | --- | --- |
| `no` | 札の番号。0 が序歌 | 公開の本文データ |
| `phrases[].text`、`kana` | 句ごとの本文と歴史的仮名遣いの仮名 | 公開の本文データ。序歌だけ手で入れた |
| `phrases[].parts` | 漢字のかたまりと読みの組 | 公開データの本文と仮名を重ねて作る。一覧のふりがなは使わない |
| `phrases[].sound` | 読むときの音を今の仮名で書いた列 | 仮名に読み替えの規則を当てて作る |
| `phrases[].diffs` | 仮名と発音が違う箇所。仮名の位置、元の字、読み替えた字、規則を持つ | 同上 |
| `kimariji` | 決まり字。仮名の形と発音の形。序歌は `null` | 発音から計算する |
| `ruleStretches` | 規則から出る伸ばす位置 | 計算する。四句の途中は規則から出ないので入らない |
| `stretches` | 札ごとの伸ばす箇所 | 読手テキスト抜粋版の読み方一覧の本文の列の印 |
| `marked` | 本文に「ー」を置いた形 | `stretches` から計算する |
| `origin` | 本文の修正、発音の例外、伸ばす箇所のページ | 札ごとの由来 |

伸ばす位置の `after` は、句の頭から数えた仮名の字数である。発音の位置へは `soundOffset`、逆は `kanaOffset` で移す。字数が変わる読み替えは「けふ」と「てふ」である。測定で使うときは、対応づけの定義を `docs/measure.md` に書く。

## 許可の範囲

許可の範囲は `REVIEW.md` の「資料の範囲」で決め、資料の名前と版は `NOTICE.md` の「協会の資料」にある。伸ばす箇所の基準は抜粋版の令和7年4月1日改訂版である。

表は本文の列の印だけを使う。ふりがな、別の読み、注などの列を足すときは、`REVIEW.md` の表に従い、札ごとに由来の版とページを `origin` に残す。

発音の列は、歴史的仮名遣いの一般の読み替えの規則を仮名に当てて作る。規則だけでは決まらない語の切れ目が23か所あり、一覧のふりがなと比べて見つけて、`scripts/cards/corrections.ts` に足した。一覧のふりがなの字は表に持たないが、発音の列の結果は一覧の読みと同じ音になる。

本文は公開の本文データを使い、4札は一覧の形に合わせた。33番、44番、74番と序歌である。札の `origin` に残す。序歌は競技かるたで読む形で、四句の頭が一般の形の「今は」と違う。違いは[ウィキペディアの「難波津の歌」](https://ja.wikipedia.org/wiki/難波津の歌)で確かめた。

規則のうち、下の句の終わりを三字前にする語尾は、抜粋版 p.4 の決まりにある形である。一覧の印から逆算していない。

## 作り方

資料はリポジトリの外に置く。`build.ts` は版のハッシュを確かめてから読む。

| 資料 | 場所 | SHA-256 |
| --- | --- | --- |
| 歌の本文 | [nyoronjp/Ogura_Hyakunin_Isshu.csv](https://github.com/nyoronjp/Ogura_Hyakunin_Isshu.csv) のコミット `42cfd44` の `小倉百人一首.csv` | `f99510dcd54838a2be3bc8cd2e96d2063d799705248615906a939b4dcaeaf34b` |
| 読み方一覧 | [協会の読手のページ](https://www.karuta.or.jp/karuta/reading/)の抜粋版 PDF | `ae619e9a8a75e1702014f0c41d53b7ae8c32d3015926985090ad8a4c6c182a77` |

```bash
node scripts/cards/build.ts --csv <小倉百人一首.csv> --pdf <抜粋版.pdf>
```

実行には poppler の `pdftotext` が要る。CI では使わない。

`scripts/cards/list.ts` が語の座標から本文の列とふりがなの列を分ける。本文の右の2列目は読まない。序歌と100首が1枚ずつそろわなければ止まる。`build.ts` は発音と印を一覧と比べ、すべて合うときだけ表を書く。

本文データには誤りがあるので、`scripts/cards/corrections.ts` で直し、札の `origin.text.fixes` に残す。上の3札のほかに、データの漢字の列の誤り7か所、伸ばす箇所を示すために仮名へ開いた3か所、語の扱いのために書き方を変えた1か所がある。

## 検算

### CI で確かめること

`test/cards/` のテストである。資料がなくても動く。

- 101枚そろい、どの札も5句で、字数は 5、7、5、7、7 に字余り1字までである。
- 字余りは32首、初句が6字の札は8首、1音目が母音の札は28首である。
- 決まり字は一意で、字数の内訳は 7、42、37、6、2、6 首である。6字決まりは大山札の6首と一致する。
- 札ごとの伸ばす箇所は、規則の位置に四句の途中の1か所を足したものである。例外は63番だけである。
- 印は100首で694か所、上の句394、下の句300である。下の句の終わりが三字前の札は11首である。
- 発音の列は、仮名に `diffs` を当てたものと一致し、歴史的仮名遣いの字を含まない。
- どの札にも由来があり、札と句に決めた項目のほかを持たない。

### 公開の一覧と照らす手順

```bash
node scripts/cards/build.ts --csv <小倉百人一首.csv> --pdf <抜粋版.pdf> --check
```

一覧の本文の仮名、ふりがなをかぶせた読み、伸ばしの印を表と比べ、資料から作り直した表とも比べる。合わない札の番号と件数だけを出し、一覧の本文は出力しない。不一致があると exit 1 で終わる。

比べる前に書き方の違いを揃える。長音の書き方、「を」と「お」、「ぢ」と「じ」、「づ」と「ず」は同じ音として扱う。

### 目で読み直す手順

`--check` は一覧の文字データを読むので、印刷の見え方と文字データが違っても気づけない。一覧のページの画像だけから本文の列と印を書き起こし、機械の読み取りと比べる。

```bash
node scripts/cards/build.ts --csv <小倉百人一首.csv> --pdf <抜粋版.pdf> --reread <書き起こし.tsv>
```

書き起こしは1行が「番号、上の句、下の句」のタブ区切りで、リポジトリに置かない。2026-11-03 に、表を作ったのとは別のモデルが表を見ずに画像だけで書き起こした。序歌と100首の202行、印701か所で差は0行だった。

## 機械の検算で足りない箇所

- 四句の途中の100か所は規則から出ない。CI は位置が1か所あることしか見ない。値は `--check` と目の読み直しで確かめた。
- 規則の位置のうち、句の字数から出るのは494か所である。上の句の終わりの手前の100か所は、札の番号を一覧の印で決めたので、一覧との比較は独立の検算にならない。二字前の25首のテストも同じである。
- お手本の音声とは照らしていない。
- 「を」は発音の列ですべて「お」にした。これは位置の対応づけのための扱いで、読み分けの判断ではない。教科書の説明には使わない。
- 発音の比較は上の書き方の違いを揃えて行うので、その違いは検算に出ない。
- 本文の漢字の列は公開の本文データのままで、一覧の表記とは202行のうち116行が違う。読みが同じことだけを確かめた。
- 序歌の本文は手で入れた。公開の本文データとは照合できない。
- 決まり字は発音から計算した。一意であることと字数の内訳を確かめただけで、札ごとに別の資料と比べてはいない。
