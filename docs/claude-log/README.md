# Claude の利用の記録

開発のどこを Claude に任せ、どこをユーザーが決めたかを、日付ごとに残す。

- 1日分を `YYYY-MM-DD.md` に書く。
- その日の終わりに、GitHub の Issue と PR から集めて書く。PR の中から書くと、同じファイルへの追記が衝突する。
- 日付だけを書き、時刻は書かない。
- 「ユーザーの判断」には、ユーザー本人の言葉で確かめられることだけを書く。

各日のファイルの見出しは次のとおりである。

1. 任せた作業
2. ユーザーの判断
3. 見つかった失敗
4. 確かめたこと
5. 確かめていないこと
6. 使ったスキルと、`/yomimasu` の件数

実行ごとのモデル、ターン数、トークンは、PR の要約のコメントに残す。実行の全文の記録は公開しない。
