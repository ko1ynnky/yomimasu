## このアプリについて

<div class="card rows points">
<div><b>公認ではありません</b><p>このアプリは独立したプロジェクトです。全日本かるた協会の公認を受けていません。Anthropic の製品やデモではありません。</p><p lang="en">Independent project. Not affiliated with or endorsed by the All-Japan Karuta Association or Anthropic.</p></div>
<div><b>作り方</b><p>Claude Code を使って作りました。Claude Code は道具として使ったもので、このアプリを Anthropic が作ったり、確かめたりしたものではありません。</p></div>
<div><b>録音</b><p>録音は端末の外へ出ません。測るのも、結果を出すのも、この端末のブラウザーの中です。録音と結果はこのブラウザーに残り、「前回と比べる」の画面で消せます。</p></div>
<div><b>アクセス解析とボット対策</b><p>このサイトを配信している Cloudflare が、どのページにも2つのスクリプトを差し込みます。このアプリのコードではありません。このアプリのコードは、録音と測った結果をこの2つに渡しません。</p><p>アクセス解析（Cloudflare Web Analytics）：開いたページ、どこから来たか、表示にかかった時間を Cloudflare へ送ります。Cookie は使いません。Cloudflare はこれを国、ブラウザー、OS、端末の種類と合わせて集計し、作者はその集計だけを見ます。</p><p>ボット対策（Bot Fight Mode）：ブラウザーの特徴を Cloudflare へ送り、人が開いているかを判定します。結果は cf_clearance という Cookie に1年残ります。送る中身は暗号化されていて、作者は見られません。</p></div>
<div><b>お手本の音声</b><p>お手本の音声は「A級公認読手のお手本」と書き、読手の名前は書きません。序歌と100首の上の句と下の句のお手本を、許諾を得て使っています。</p></div>
</div>

<h2 id="sources">出典</h2>
<p class="fine">教科書の各ページは、項目のそばに「冊子 p.23」「講習資料 s.19」「読手のメモ1 要点2」のような短い印だけを付けています。印が指す資料を、ここにまとめています。印の中の「（大会向け）」は、大会やきちんとした練習会での話で、ふだんの練習会では参考程度にしてください。解説の文はこのアプリの言葉で書きました。資料の文と違う所があれば、資料が正しいものとしてください。</p>

<h3 id="src-uta">歌の本文</h3>
<div class="card sources">
<p>100首の本文：<a href="https://github.com/nyoronjp/Ogura_Hyakunin_Isshu.csv">nyoronjp/Ogura_Hyakunin_Isshu.csv</a>（コミット 42cfd44）の漢字の列と仮名の列を使い、誤りを直しました。データのリポジトリは Unlicense で、Public Domain としています。データの作者がどの資料から書き起こしたかは分かりません。歌そのものは古典です。</p>
<p>序歌の本文：公開の本文データにないので、手で入れました。読手テキストの読み方一覧（p.5）にある、競技かるたで読む形です。一般の形とは四句の頭が違います。元の歌は古今和歌集の仮名序に引かれる古典です。</p>
</div>

<h3 id="src-text">読手テキスト（冊子、抜粋版）</h3>
<div class="card sources">
<p><b>冊子</b>：全日本かるた協会 競技かるた部（読唱）『小倉百人一首 競技かるた読手テキスト』冊子、令和2年4月1日初版。印は「冊子 p.ページ」です。解説と、ふりがな、注、別の読み、余韻の印に使っています。</p>
<p><b>抜粋版</b>：同じテキストのHP掲載用抜粋版、令和7年4月1日改訂版。印は「抜粋版 p.ページ」です。伸ばす箇所と5・3・1・6の方式に使っています（読み方一覧 p.5-15）。</p>
<p>どちらも、協会から得た回答の範囲で使っています。ふりがな、注、別の読み、余韻の印では、抜粋版だけにある値と、抜粋版と冊子で違う値は入れていません。読手テキストのページそのものは載せていません。</p>
<p>伸ばす箇所は、抜粋版の読み方一覧のどのページから来たかを、札ごとに記録しています。ふりがな、注、別の読み、余韻の印の値は、抜粋版の文字のデータと画像の位置から読み取り、冊子のスキャンと目で照らしました。ふりがなは707か所のうち706か所を、注、別の読み、余韻の印はすべてを、目で照らして一致を確かめました。残る1か所（33番）は、読み方一覧のスキャンで濁点が判別できなかったので、冊子の別のページ（p.27）が同じ語を「しづごころ」と印刷していることと、冊子の実物で確かめました。</p>
<p>発音の列は規則で作り、語の切れ目は読み方一覧のふりがなと比べて確かめました。そのうえで読み方一覧のふりがなの「ー」と注の字を当てたので、30句の発音はその値を含みます。54番の四句の1か所は、制作者の判断で読み方一覧の「ー」を当てていません。33番、44番、74番の本文は、読み方一覧の形に合わせました。</p>
</div>

<h3 id="src-lecture">講習資料</h3>
<div class="card sources">
<p>全日本かるた協会『読手講習ビデオ（PDF版）』2020年10月。協会のサイトで公開されている PDF です。印は「講習資料 s.スライドの番号」です。</p>

<h3 id="src-memo">読手のメモ</h3>
<div class="card sources">
<p>A級公認読手が書いたメモ2本です。読手のメモ1は初めて読む人向け（2018年作成、2022年更新）、読手のメモ2は大会で読む人向け（2020年作成、2022年更新）です。著者から使う許可を得ています。協会の基準ではなく、読手個人のやり方です。印は「読手のメモ1 要点2」のように、メモの番号と項目で書きます。「ポイントを知る」では、段落の終わりに「— 読手メモより」とだけ付けます。印はその段落の全体の出どころを指します。読手のメモ2から来た大会向けの項目は「— 読手メモ（大会向け）より」とし、大会やきちんとした練習会での話なので、ふだんの練習会では参考程度にしてください。</p>
</div>

<h3 id="src-author">作者の経験</h3>
<div class="card sources">
<p>このアプリの作者の個人の考えと、自分で読んで確かめた経験です。協会の資料でも読手のメモでもありません。「ポイントを知る」では、段落の終わりに「— このアプリの作者の実体験より」と付けます。「— このアプリの考え」は、研究や資料にない、このアプリの解釈です。</p>
</div>

<h3 id="src-audio">お手本の音声</h3>
<div class="card sources">
<p>A級公認読手の読みです。序歌と100首の上の句と下の句（202本）を、読手本人と録音した人の許諾を得て使っています。読手の名前は書きません。音声は録音した人の権利のままで、再利用を認めません。例の録音は、このアプリの作者が自分で読んで録音したものです。</p>
</div>
