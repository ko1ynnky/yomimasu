# 教科書

`content/` の総論、最低限これだけ、ポイント、100首の一覧と、札の読みの表から組み立てる1首のページ（`/karuta/<番号>/`、序歌は `/karuta/joka/`）。

## 確かめること

- JS を切っても、どのページも本文を読め、一覧から1首のページへ移れる。
- 本文に `{{札` が残っていない。札は決まり字のリンクになっている。
- 1首のページに歌番号が出ない。歌は縦書きで、伸ばす印、ふりがな、余韻の印がある。
- 100首の一覧で、決まり字順と歌番号順、多い→少ないと少ない→多いを切り替えられる。
- 幅 360px と 393px で横スクロールがない。
- 101ページすべてが開ける。
- 「ポイントを知る」の作者の経験のカードに、あ・い・う・え・お・ん の口の形の図が6つある。折りたたみを開くと「ん」の断面の図と「ん」で終わる札の数が出る。1首のページには、その札の最後の音の図が1つだけある。図の文字が線に重ならない。

## Playwright での動かし方

`e2e/textbook.spec.ts`。393px の画面の画像を `e2e-artifacts/textbook-*.png` に残す。口の形の図は `e2e/mouth.spec.ts` で、画像を `e2e-artifacts/mouth-*.png` に残す。

## 注意

- 規則が当たる札は `test/site/karuta.test.ts` がスキルの `card-rules.md` の札と照らす。表か規則を変えてテストが落ちたら、`card-rules.md` の札と件数を先に確かめる。
- 解説の文が読手テキストの文と合っているかは、テストでは確かめられない。ユーザーが照らす。
