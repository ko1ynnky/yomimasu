# 帯と歌詞の枠

読む画面の上に、帯と、歌詞と帯をまとめた枠を出す。見た目の基準は `docs/ui-guide.md` の7節と `docs/ui-sample.html` である。

## 確かめること

- 帯は 5・3・1・6 の順に、区間の名前と秒数を2行で出し、文字が区間から切れない。
- 歌詞は札の読みの表から描き、伸ばす箇所に朱の「ー」を置く。文字は進めない。
- URL の `?shimo=<札>&kami=<札>` で歌が替わる。指定がなければ 77番と29番である。

## 利用者の経路

`/read/rec/` を開き、帯と歌詞を見る。`/read/rec/?shimo=53&kami=86` でも開く。

## Playwright での動かし方

`e2e/stage.spec.ts` のとおり、帯は `getByRole('img', { name: '下の句 5秒、余韻 3秒、間 1秒、上の句 6秒' })`、歌詞は `getByTestId('lyrics')` で取る。幅 360×560 と 393×659 の画像を `e2e-artifacts/` に残す。

## 注意

- 縦書きは iOS の Safari で崩れやすい。Chromium の E2E では見つからないので、実機で確かめる。
