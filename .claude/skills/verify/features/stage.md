# 歌の枠

読む画面に、歌を下の句、余韻と間、上の句の3つの区切りに分けた枠を出す。見た目の基準は `docs/ui-guide.md` の7節と `docs/ui-sample.html` である。

## 確かめること

- 区切りは右から下の句、余韻と間、上の句と並び、縦書きの見出しに「下の句5秒」「余韻3秒」「間1秒」「上の句6秒」と出す。見出しの長さと区切りの高さはそろう。
- 下の句の最後の字は余韻と間の区切りに置き、余韻の印が続く。間の字は置かず、間の1秒は字の塗りが変わらない。
- 歌の枠に、上の帯、地の減り、区間名と残り秒数の行はない。
- 読んでいるあいだ、字は札の読みの表の拍と伸ばす印から割り振った時刻に、上から朱になる。今の区切りを黒い線で囲む。囲みが出ても字は動かない。
- 朱は読み上げた字だけに使う。伸ばす印と余韻の印は字と同じ黒である。
- 補助を外すと、朱も囲みも出さず、「補助なし」と出す。
- 表記は最初はかなで、左上の切り替えで漢字まじりにでき、端末に覚える。合図と録音のあいだは切り替えを隠す。
- URL の `?shimo=<札>&kami=<札>` で歌が替わる。指定がなければ 81番と45番である。

## 利用者の経路

`/read/rec/` を開き、歌の枠を見る。「読み始める」を押して、区切りの囲みと字の朱の進みを見る。`/read/rec/?shimo=53&kami=86` でも開く。

## Playwright での動かし方

`e2e/stage.spec.ts` のとおり、歌詞は `getByTestId('lyrics')`、区切りは `.blk[data-phase="shimo"]` などで取る。塗った割合は、字は各字の `--p`、余韻の印は `--yoin-done` で読む。表記は `localStorage` の `yomimasu.kana` を `kanji` か `kana` にして開く。幅ごとの画像を `e2e-artifacts/` に残す。

## 注意

- 縦書きは iOS の Safari で崩れやすい。Chromium の E2E では見つからないので、実機で確かめる。
- 帯の部品（`band.tsx`）は今どのページにも出ていないので、この E2E では確かめていない。
