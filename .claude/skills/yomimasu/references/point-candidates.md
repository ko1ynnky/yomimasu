# 「ポイントを知る」の注意点の候補

教科書の「ポイントを知る」に載せる注意点を、ユーザーが選んで絞るための材料である。ページにそのまま出す本文ではない。順位は付けていない。順位と、どれを載せるかはユーザーが決める。

2026-11-05 に、先に全部入れてから削る、というユーザーの方針で、教科書の `content/ポイント.md` に全項目を入れた。ページの文は、各行の出典の知識のファイルから書き直したもので、このファイルの要点の文そのものではない。優先の高・中・低は Claude の案で、ページに「このアプリの案」と断ってある。順位と、どれを残すかはユーザーが決める。

- 1項目1行で、要点は短く言い換えた。詳しい説明は、各行の出典に当たる知識のファイルにある。
- 区分の列は、出どころ（協会の資料か、読手のメモか）と、札によらない総論か、特定の札に関わる札別かを示す。「大会向け（参考程度）」は、大会やきちんとした練習会で読むときの話で、ふだんの練習会では参考程度にとどめる項目である。読手のメモは、A級公認読手が自分のやり方として書いたもので、協会の基準ではない。
- 関わる札の番号は [card-rules.md](card-rules.md) にある。「全札」は札によらないことを示す。

- 講習資料とメモから来た行は、教科書（`content/`）でも使える（リポジトリの `REVIEW.md` の「資料の範囲」）。メモから来た行は、教科書でも読手個人のやり方として分けて書く。

資料の呼び名と由来の書き方は [README.md](README.md) にある。
