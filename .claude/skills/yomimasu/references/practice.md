# 練習の方法

一人でできる読みの練習と、自分の読みの確かめ方をまとめる。録音で測る項目の定義は、リポジトリの `docs/measure.md` にだけある。

資料の呼び名と由来の書き方は [README.md](README.md) にある。

## 協会の資料

### 初句をくり返す

- 決まり字までの読み（審査の1と2の項目）には、初句だけをくり返し読む練習を勧める。例えば「ちぎりきな」だけを何度も読み、速さ、一定さ、発音を確かめる。自分が競技者になったつもりで、競技者の感覚に合う読みになっているかを外から聞く（講習資料 s.17）。
- 初句は短いので、録音してその場で聞き直せる。スマートフォンで録音すればよい（講習資料 s.17）。
- 一定さを確かめるため、友札も続けて読む。「ちぎりきな」と「ちぎりおきし」のように字数の違う友札では、長さではなく速さをそろえる。そろったら伸ばしも入れて、続けて読み比べる。こうした部分の練習と比べる練習で、自分の読みを点検する（講習資料 s.18）。
- 1字決まりの7首を初句のリピートで続けて読む。くり返すと読みが安定する（講習資料 s.20）。
- 決まり字までは正しくはっきり発音できるよう、くり返し練習する（完全版 p.28）。

### 余韻と間合いを身につける

- 余韻と間合いは秒を数えて身につける。秒針のある時計で1秒の感覚を覚え、指先で刻む。慣れると頭の中で数えられ、やがて数えなくてもよくなる（講習資料 s.23）。数え方の詳しい手順は [timing.md](timing.md) にある。
- 余韻の間に口の形が変わっていないかを鏡で確かめる（講習資料 s.25）。

### 自分の読みを聞く

- 時間に余裕があれば、自分の読みを録音して、どこを直すかを自分で分析する（講習資料 s.26）。
- 競技者から感想をもらう。公式の大会では次の試合に響かないよう、練習会で読んだときに聞く（講習資料 s.26）。
- 同じ読みでも、人によって感想が違うことがある。1人の意見がすべてではない。読みは、すべての競技者に同じように届くわけではない。会場の広さと読手からの距離、競技者の暗記の状態、マイクの性能やスピーカーの位置、飛沫を防ぐ道具で、聞こえ方が変わる（講習資料 s.26）。

### 姿勢

- 「正しく読む」「美しく読む」という課題に正面から向き合い、工夫して自分の読みの質を高めようとする姿勢が、読手に望まれる（完全版 p.25）。

## 読手のメモ（読手個人のやり方）

協会の基準ではなく、A級公認読手が自分のやり方として書いたものである。

- メモ1に挙げた読み間違えやすい所を直せば、練習会でも自信を持って読めるようになる、と著者は書く。興味があれば講習会に出て公認読手の資格を取るよう勧める（メモ1 結び）。
- メモ2に書いたことをまずやってみて、少しずつ自分に合うように変えていけばよい、と著者は書く（メモ2 最後に）。
