# 歴史的仮名遣いの読み方

歌は歴史的仮名遣いで書かれている。読むときにどの音へ読み替えるかの決まりと、読み方一覧の書き方をまとめる。札ごとの発音は表 `.claude/skills/yomimasu/assets/cards.json` の `phrases[].sound` にあり、読み替えた箇所は `diffs` にある。ある決まりがどの札に当たるかは [card-rules.md](card-rules.md) にある。

「を」の読み方は、このフォルダーにまだ入れていない。問われたら、知識がないと伝える。

資料の呼び名と由来の書き方は [README.md](README.md) にある。

## 協会の資料

### 2つの原則

- 原則1：語の頭にないハ行の音は、ワ行かア行の音で読む。「あはれ」は「あわれ」、「あひみて」は「あいみて」、「ながらへ」は「ながらえ」になる（完全版 p.23）。
- 原則2：母音の後に「う」の音が続くと、音が変わって長音になる。原則1で「ふ」を「う」にしてから当てる。例えば「あふこと」は「あうこと」を経て「おーこと」、「いふべき」は「ゆーべき」、「ゆふぐれ」は「ゆーぐれ」、「けふ」は「きょー」、「おもふ」は「おもー」になる（完全版 p.23）。
- 「まがふ」は「まごー」、「こひすてふ」は「こいすちょー」と、同じ決まりで読む（完全版 p.23）。

### 原則の例外とそのほかの決まり

- 2つ以上の語が合わさってできた語では、後ろの語の頭のハ行は変えない。「潮干（しほひ）」は「しおひ」と読み、「しおい」とは読まない。「朝日（あさひ）」も「あさい」とは読まない（完全版 p.23）。
- 「いま はた おなじ」の「はた」は語の頭なので変えず、「いまはた」と読む（完全版 p.23）。
- 助動詞の「む」「らむ」「けむ」の「む」は「ん」と読む。発音が「ン」に変わり、それに合わせて書き方も「ん」になった語である（完全版 p.24）。
- 副詞の「むべ」は「むべ」と読む。一時は「うべ」と読むことにしていたが、今の言葉にも「むべなるかな」という使い方があることなどから、平成11年5月に「むべ」にそろえた（完全版 p.24）。
- 「もがな」「もがも」は1つの終助詞として読み、途中で伸ばさない（完全版 p.24）。
- 「ゐ」「ゑ」は「い」「え」、「ぢ」「づ」は「じ」「ず」と読む。読み方一覧のふりがなで確かめられる。例えば17番の「くれなゐ」には「い」、69番の「もみぢ」には「じ」とふりがながある（完全版 p.12、p.5）。

### 読み方一覧の書き方

- 読み方一覧は、序歌と100首を出だしの字ごとの組に分けて並べ、上の句と下の句を分けて載せる。最後の組は1字決まりの7首である（完全版 p.5-15。抜粋版も同じページ）。
- 本文の「ー」は伸ばす所を示す。完全版 p.3 の読唱の例も、伸ばす所を同じ「ー」で書いている（完全版 p.3、p.5-15）。伸ばす位置の決まりは [stretches.md](stretches.md) にある。
- 本文の横のふりがなで読む音を示す。長音になる所は「ゆー」「おー」「きょー」のように「ー」で示す。例えば8番の「いふなり」の「いふ」には「ゆー」、61番の「けふ」には「きょー」とある（完全版 p.8、p.12）。
- 括弧に入れた小さな仮名を添えた札が10首ある（完全版 p.5-15）。札の番号は [card-rules.md](card-rules.md) にある。括弧の意味を説明する文は資料にない。このフォルダーでは、（お）を「ー」とは別の読みとして扱う（2026-11-04 のユーザーの判断）。一覧は20番と77番の「思ふ」に（お）を添え、40、48、85、99番の「思ふ」は「ー」で書いて、書き分けている。95番の三句は、2020年の改訂で「ー」を「（お）」に改めた（講習資料 s.31）。（お）がどういう音かと、（お）のほかの注の読みは決めていない。表の発音の列は注の所を注の字で書き、20番と77番の「思ふ」は「おもお」、44番の「逢ふことの」は「おおことの」、95番の三句は「おおおかな」になる。原則2の例の「おもふ」→「おもー」と「あふこと」→「おーこと」は、注のない札の読みである。完全版 p.28 は、2音目がもともと長音に近い札の例に「ゆ(う)ー」「お(お)」を挙げている。
- 本文の横に、もう1つの読み方を小さく並べた札が10首ある。大山札の6首と、四句の伸ばし方が2通りある4首である（完全版 p.6-13）。札の番号は [card-rules.md](card-rules.md) にある。

## 読手のメモ（読手個人のやり方）

協会の基準ではなく、A級公認読手が自分のやり方として書いたものである。

- 歴史的仮名遣いと漢字の読み間違いで多いものを6つ挙げる（メモ1 読み違い①〜⑥）。
  - 1番の「かりほ」は「かりお」と読む。
  - 97番の「まつほ」は「まつお」と読まない。
  - 17番は「ちはやふる」ではなく「ちはやぶる」と読む。
  - 28番は「さみしさ」ではなく「さびしさ」と読む。
  - 20番の「いまはた」は「いまわた」と読まない。
  - 92番の「しほひ」は「しおい」ではなく「しおひ」と読む。
- 母音を1つずつはっきり発音しないのが正しい所、つまり長音にする所を16首について挙げる。例えば78番の「かよふ千鳥」は「かよーちどり」、45番の「いふべき人」は「ゆーべきひと」と読む（メモ1 長音の一覧）。メモの読みが表の読みと違う札が3首ある。77番と95番は、メモが「ー」で長音にする所に読み方一覧が（お）の注を添えていて、読みが違う。54番の「けふ」は、メモは「きょー」と長音にし、表はユーザーの判断で伸ばさずに「きょ」と読む（[card-rules.md](card-rules.md) の「長音」）。札ごとの違いは [card-advice-candidates.md](card-advice-candidates.md) にある。
- 札ごとの一覧は [card-advice-candidates.md](card-advice-candidates.md) にある。
