# 札に当てはまる規則

協会の資料にある規則や例のうち、札の番号で示せるものを、規則ごとにまとめる。教科書の1首のページで、札ごとの注意点を全札分導くための土台にする。

各規則には、決まり、どの札に当たるかを判定できる条件、当たる札、出典を書く。条件の値は表 `.claude/skills/yomimasu/assets/cards.json` の項目名で書き、表の説明はリポジトリの `docs/cards.md` にある。番号は序歌（0）を除いた100首の歌番号である。

件数は、条件を `cards.json` に当てて数え（2026-11-04）、資料の件数と照らした。別の読みと括弧つきの注は、資料を目で見て数え、表に足す列の札と照らした。品詞分解の印は表に値がないので、資料を目で見て数えた。目で数えた規則にはそう書いた。

資料の呼び名と由来の書き方は [README.md](README.md) にある。

## 決まり字と初句

- 決まり：二句目までを一気に読む。二句目の語の切れ目でわずかに伸ばしてもよい。決まり字までが長いので読み急がない。
- 条件：`kimariji.kana` が6字である。
- 当たる札：6首。11、15、31、50、64、76
- 出典：完全版 p.3、p.27、講習資料 s.10。資料の「全六首」と一致する。

### 1字決まり

- 決まり：資料が名指しする規則はない。講習資料は、1字決まりの7首を初句のリピートで続けて読む練習を勧め、「さ」「す」「せ」で子音を強く出しすぎないよう注意する。
- 条件：`kimariji.kana` が1字である。
- 当たる札：7首。18、22、57、70、77、81、87
- 出典：完全版 p.15（「む・す・め・ふ・さ・ほ・せ」の組）、講習資料 s.20、s.21。

### 初句が6字の札（字余りの初句）

- 決まり：初句で一定にするのは長さではなく速さである。6字の初句は5字の初句より1字分長くなる。

### 字余りの句がある札

- 決まり：資料が名指しする規則はない。初句の字余りの説明の前置きとして件数が出てくる。
- 条件：`phrases[i].kana` の字数が、5、7、5、7、7 のどれかを超える句がある。
- 当たる札：32首。1、4、9、11、15、16、20、21、22、23、24、25、26、28、29、31、38、40、48、49、55、57、70、73、75、76、77、79、80、85、92、99

### 1音目が母音の札

- 決まり：協会の資料には、この札を名指しする規則はない。完全版は、1音目の子音が落ちると母音だけが届き、別の札に聞こえると注意する（下の「1音目の子音が落ちたときに聞こえる札」）。読手のメモは、1音目が母音の札は2音目に早く入りがちなので、1音目を少し長めにすると書く（読手個人のやり方）。

  - 内訳：「あ」16首、「い」3首（21、61、63）、「う」2首（65、74）、「え」0首、「お」7首（5、26、44、60、72、82、95）
- 出典：完全版 p.27、メモ2 2-5。

## 発音

### ガ行鼻音

- 決まり：ガ行の音が語の途中か語の終わりにあるときは、原則として鼻濁音で読む。
- 条件：`phrases[].sound` の中のガ行の字（が、ぎ、ぐ、げ、ご）で、句の頭にないもの。句の頭にガ行の字がある札はない。
- 当たる札：60首、のべ88か所。当たらないのは次の40首である。5、10、14、16、18、20、22、24、28、30、31、35、37、38、39、43、44、45、46、48、49、58、59、60、61、62、65、66、67、69、71、72、78、82、83、88、90、94、99、100
- 出典：完全版 p.27、p.29、p.33-34。完全版の一覧表の「計60首 のべ88箇所」（序歌を除く）と、札の顔ぶれも件数も一致する。序歌には1か所ある。

### 語の頭でないハ行の読み替え

- 決まり：語の頭にないハ行の音は、ワ行かア行の音で読む。ただし2つ以上の語が合わさった語では、後ろの語の頭のハ行は変えない。
- 条件：読み替えるのは、`phrases[].diffs` の `rule` が「語中のハ行」の箇所。語の頭なので変えないのは、`origin.sound.kept` の `why` が「語の頭」でハ行の字の箇所。
- 当たる札：読み替えは85首、のべ167か所。当たらないのは次の15首である。3、6、7、14、22、26、31、33、34、44、76、79、81、91、94
- 語の頭なので変えない箇所がある札：13首。9、17、20、23、26、39、56、58、60、66、69、77、85
- 出典：完全版 p.23。

### 長音になる綴り

- 決まり：母音の後に「う」の音が続くと長音になる。「てふ」「いふ」「あふ」「けふ」「がふ」は、それぞれ「ちょー」「ゆー」「おー」「きょー」「ごー」と読む。
- 条件：`phrases[].diffs` の `rule` が「長音」である。表はこの形を「ちょう」「ゆう」のように書く。
- 当たる札：14首、のべ14か所。2、8、10、22、25、41、44、45、54、56、61、62、63、76
- 出典：完全版 p.23。
- 限界：「おもふ」を「おもー」と読むような長音は、表では「語中のハ行」の読み替え（ふ→う）として記録されていて、この条件には入らない。

### 「む」を「ん」と読む

- 決まり：助動詞の「む」「らむ」「けむ」の「む」は「ん」と読む。
- 条件：`phrases[].diffs` の `rule` が「む」である。「む」のまま読む箇所は、`origin.sound.kept` の `kana` が「む」の箇所（語の一部が8首、語の頭が1首）。
- 当たる札：22首、のべ22か所。3、12、16、18、20、21、22、26、27、29、33、34、36、56、63、65、67、73、77、80、84、91
- 「む」のまま読む箇所がある札：9首。8、15、24、47、69、70、81、91、94
- 出典：完全版 p.24。

### 「ゐ」「ゑ」「ぢ」「づ」

- 決まり：「ゐ」「ゑ」は「い」「え」、「ぢ」「づ」は「じ」「ず」と読む。読み方一覧のふりがなで確かめられる。
- 条件：「ゐ」「ゑ」は `phrases[].diffs` の `rule` が「ワ行」で `kana` が「ゐ」か「ゑ」の箇所。「ぢ」「づ」は `rule` が「四つ仮名」の箇所。同じ「ワ行」の規則にある「を」は、このフォルダーで扱わない。
- 当たる札：
  - 「ゐ」3首。17、58、76
  - 「ゑ」9首。5、14、42、49、54、77、78、88、99
  - 「ぢ」「づ」26首、のべ27か所。5、8、9、12、14、17、18、23、24、25、26、27、32、33、36、39、45、46、63、64、69、70、71、78、79、99
- 出典：読み方一覧のふりがな（完全版 p.5-15）。

### 決まり字の中の母音の無声化

- 決まり：母音の i と u は、無声の子音に挟まれると無声になりやすい。完全版は決まり字の中だけで12の例を挙げる。読み方は [voice.md](voice.md) にあり、完全版と講習資料で書き方が違う。
- 条件：決まり字の発音（`kimariji.sound`）の中に、イ段かウ段の無声の子音の字（き、し、ち、ひ、く、す、つ、ふ）があり、`phrases[0].sound` でその次の字がカ・サ・タ・ハ・パ行である。
- 当たる札：12首。12、13、17、22、23、33、35、51、53、69、79、99
- 出典：完全版 p.30。完全版の12例と札が一致する。

### 1音目の子音が落ちたときに聞こえる札

- 決まり：1音目の子音がうまく出ず母音だけが届くと、別の札に聞こえる。
- 条件：表から出す条件は資料にない。完全版が挙げた例をそのまま札の番号で示す。全札の一覧ではない。
- 当たる札（読んだ札 → 聞こえる札）：
  - 「たき」55 → 「あきの」1
  - 「たま」89 → 「あまの」7
  - 「よも」85 → 「おも」82
  - 「よを」62 → 「おおこ」44
  - 「ゆら」46 → 「うら」65
  - 「もも」100 → 「おも」82
  - 「む」87 → 「うら」65
  - 「ほ」81 → 「おと」72
  - 決まり字が変わっていく途中では、「やま」（28、32）を「あま」（7、12）と、「かさ」（6）を「あさ」（31、39、64）と取り違えることもある。
- 出典：完全版 p.27。札の番号は、資料の決まり字を歌に当てて付けた。
