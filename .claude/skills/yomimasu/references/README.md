## 書き方の決まり

- [mouth-shapes.md](mouth-shapes.md) は、一般の音声学の公開の資料と研究から書いた。協会の資料にある点（余韻の間に口の形を保つこと、鏡で確かめること）は、由来を付けて指すだけにした。メモは使っていない。「研究でわかっていること」「このアプリの解釈」「作者の見解」の節に分けてあり、出典はファイルの末尾にある。
- テーマのファイルは「協会の資料」と「読手のメモ（読手個人のやり方）」の節に分けてある。[card-rules.md](card-rules.md)、[card-advice-candidates.md](card-advice-candidates.md)、[point-candidates.md](point-candidates.md) は、区分の列か「読手個人のやり方」の断り書きで分けてある。メモは協会の基準ではない。答えるときも、メモから来た内容は読手個人のやり方として書く。
- 「作者の見解」の節は、このアプリの作者の個人の考えである。協会の資料ともメモとも分けて書き、答えるときも作者の考えとして書く。由来は書かない。
- このスキルは協会の公認を受けていない。協会の資料から来た内容も、協会の見解として答えない。
- 項目ごとに、行の終わりに由来を（完全版 p.26）のように書く。由来のない文は、資料の外の説明か、このリポジトリの表についての説明である。
- 資料どうしで書き方が違う所は、どちらかに寄せずに並べて書く。
- 講習資料は令和2年版のテキストの解説で、その後の改訂を含まない。

## まだ入れていない知識

次のことは、このフォルダーにない。問われたら、知識がないと伝え、推測で答えない。

- 「を」の読み分け。
- 間の幅の目安。
- 44番と93番の二句で、2020年の改訂の前の読みを認めるかどうか。版で書き方が違い、協会に確かめている。
- 子音の調音点と調音法。[mouth-shapes.md](mouth-shapes.md) には、母音と「ん」の口の形と、「ん」の研究を読むのに要る鼻音の説明だけがある。読手テキストの調音点・調音法の一覧と口腔断面図の内容は、どの形でも入れない。
- 録音で測る項目の定義。定義はリポジトリの `docs/measure.md` にだけある。
