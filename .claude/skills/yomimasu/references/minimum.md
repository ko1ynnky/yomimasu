# 最低ライン

初めて読む人がまず押さえる点と、公認読手の審査でとくに重く見る項目をまとめる。どれも協会の資料か読手のメモから来たもので、このリポジトリが決めた基準ではない。

録音で測る項目の定義は、リポジトリの `docs/measure.md` にだけある。下の審査の項目は、このリポジトリが録音から判定するものではない。測っていない項目を点数で示さない（`REVIEW.md` の「マージを止める項目」）。

資料の呼び名と由来の書き方は [README.md](README.md) にある。

## 協会の資料

### 公認読手の審査で見る項目

講習資料は、公認読手の選考で使う審査用紙の8項目を示し、これを見ると読みのポイントがよく分かると述べる（講習資料 s.15）。項目と、それぞれで見る点は次のとおりである。見る点の言葉はこのファイルで言い換えた。

| 項目 | 見る点 |
| --- | --- |
| 1 決まり字までの読み（発音・アクセント） | はっきり発音しているか。なめらかで自然か。1音目と2音目が低高の形で毎回そろっているか |
| 2 決まり字までの読み（速度・一定性） | 速すぎも遅すぎもせず、毎回同じ速さか。友札どうしで読み方がそろっているか |
| 3 余韻（3.0秒） | 毎回ほぼ同じ長さか。3.0秒に近いか。自然に消えていき、選手が集中しやすいか |
| 4 間合い（1.0秒） | 毎回ほぼ同じ長さか。1.0秒に近いか。息を吸う音や音漏れなどの雑音がないか |
| 5 読みの正確さ | 歴史的仮名遣いなどの読み誤りがないか。伸ばす位置がテキストのとおりか。序歌と100首で読みとばしや重ね読みがないか |
| 6 声の力強さ | 腹から出た力のある声か |
| 7 全体的なバランス | 早口にならず安定しているか。余韻の前の2字（3字の札は3字）が間延びしていないか。伸ばしが長すぎも短すぎもしないか |
| 8 音程 | 高すぎも低すぎもせず聞き取りやすいか。最後まで変わらず安定しているか |

- 1から4はとくに重要である。1と2は決まり字までの読み、3と4は余韻と間合いで、どれも競技者が読みに集中する所である（講習資料 s.15-16）。
- 1から4の詳しい話は、[first-phrase.md](first-phrase.md)、[voice.md](voice.md)、[timing.md](timing.md) にある。5は [avoid-misreading.md](avoid-misreading.md) と [kana-reading.md](kana-reading.md)、伸ばす位置は [stretches.md](stretches.md) にある。

### 読手の基本と技術の要点

- 読手の基本は、公正な態度と、正確で標準的な読みである。不信感を与えない態度と、不安感や違和感を与えない読みを目指す（完全版 p.2、講習資料 s.5）。
- 完全版は、技術の面で大事な点を4つ挙げる。間合いがいつも一定であること、余韻の長さがいつも一定であること、決まり字までの速さが一定であること、協会の定めた読み方に沿っていることである（完全版 p.25）。
- そのうえで、5・3・1・6の方式に沿い、統一の読み方で「正しく読む」こと、リズムと発音に気をつけて「美しく読む」ことが要点になる（完全版 p.25）。
- 講習資料は最後に要点をまとめる。読みで競技者を戸惑わせたり不安にさせたりしない。やりすぎず足りなすぎない読みを心がける。初句の1音目から5音目までを同じくらい大事にする。はっきり発音する。余韻と間合いは秒を数える。余韻は早めに弱め始める。自分の読みを録音して外から聞く（講習資料 s.26）。

### 読手の資格

令和2年4月の完全版と、2020年10月の講習資料の時点の内容である。

- 協会の読手の資格には、専任読手、A級公認読手、B級公認読手がある。資格を得るなら、まずB級を目指す。B級は、支部が開く読手講習会に出て、専任読手の推薦を受けて委嘱される（講習資料 s.14）。
- 専任読手は三大大会で読み、読手の指導と育成に当たる。A級公認読手は、協会の主催大会と公認大会のうち三大大会を除く大会で読む。B級公認読手は、主催大会と公認大会のうちB級以下の会場で読む（完全版 p.35、講習資料 s.14）。
- 選定の基準には、段位、所属会の代表者の推薦、協会の選考会や講習会がある。専任読手は四段以上でA級公認読手の中から、A級公認読手は三段以上でB級公認読手の中から、それぞれ協会の選考会で決まる。B級公認読手は初段以上の正会員か準会員で、協会の読手講習会に出て専任読手の推薦を受けて決まる（完全版 p.35）。

## 読手のメモ（読手個人のやり方）

協会の基準ではなく、A級公認読手が自分のやり方として書いたものである。

- 初めて読む人に向けて、読手にとって大事なことを4つ挙げる。声を張る。余韻3秒、間1秒。低と高をはっきりさせる。読み間違いをしない（メモ1 要点1〜4）。
- このうち読み間違いについては、間違えやすい所を直すだけで、まともな読みになり、練習会でも自信を持って読めるとする（メモ1 結び）。
- 大会で読む人には、この4つに加えて、選手から信頼されることと、はっきり聞こえる読みが大事だとする（メモ2 冒頭）。
- B級公認読手になるには、メモ1に書いたことをすれば足りる、と著者は書く（メモ2 冒頭）。
