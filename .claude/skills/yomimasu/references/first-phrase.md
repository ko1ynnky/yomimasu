# 初句の速さ

上の句の初句と、決まり字までをどの速さで読むかをまとめる。

資料の呼び名と由来の書き方は [README.md](README.md) にある。

## 協会の資料

- 初句の5字は途中で切らずに読む。速さは1字およそ0.2秒である（完全版 p.3。抜粋版も同じページ）。
- 0.2秒はおよその目安である。実際の読みは音から音へ切れ目なくつながっていて、拍を刻んで読むわけではない。競技者に違和感のない速さで読めばよい（講習資料 s.7）。
- 速さを一定に保つのは決まり字までである。決まり字の後は、極端でなければ少し速さが変わってもよい（講習資料 s.18）。
- 公認読手の審査の「決まり字までの読み（速度・一定性）」は、速すぎも遅すぎもせず毎回同じ速さか、友札どうしで読み方がそろっているかを見る（講習資料 s.15-16）。

### 字余りの初句

- 初句が6字の札は8首ある（講習資料 s.18）。札の番号は [card-rules.md](card-rules.md) にある。
- 6字の初句は、5字の初句より1字分長くなるのが自然である。初句で一定にするのは長さではなく速さである。例えば6字の「ちぎりおきし」を、友札で5字の「ちぎりきな」の長さに詰めて読むと、読み急いで聞こえる（講習資料 s.18）。

### 大山札

- 大山札は決まり字までが長いので、二句目までを読み急ぎやすい。速すぎず遅すぎず、一定の速さを保つ（講習資料 s.10）。
- 大山札は二句目までを続けて読む。伸ばす位置は [stretches.md](stretches.md) にある（完全版 p.3）。

### 1音目から5音目まで

- 講習資料は、やりすぎもせず足りなくもない程よい読みを「中庸」と呼び、理想とする（講習資料 s.20、s.26）。
- 中庸に近づくために、初句の1音目から5音目までを同じくらい大事に読む。例えば「さびしさに」で1音目の「さ」に力が入りがちなら、後ろの「びしさに」の方に気持ちを置いて丁寧に読む（講習資料 s.20）。
- 1音目は、強さではなく、はっきりしているかが大事である。発音の話は [voice.md](voice.md) にある（講習資料 s.21）。

## 読手のメモ（読手個人のやり方）

協会の基準ではなく、A級公認読手が自分のやり方として書いたものである。

- 最初の5音を、どの札とも同じ速さで発音する。とくに「こころあてに」「ちぎりおきし」「なにしおはば」の3首と大山札に気をつける。「むらーさめーのー」のように途中で伸ばさず、「むらさめのー」と読む（メモ2 2-4）。
- 「あ」「い」「う」「お」で始まる札は、1音目に子音がないので、2音目に早く入りがちである。1音目を少し長めにすると、ほかの札と同じ時に2音目を出せる（メモ2 2-5）。1音目が母音の札は [card-rules.md](card-rules.md) にある。
- 講習資料は1音目から5音目までを同じくらい大事に読むよう勧める（講習資料 s.20）。メモの1音目を長めにするやり方とどう合わせるかは、どちらの資料にも書かれていない。
