# 時間の配分

1組の読みの長さの決まりと、余韻と間合いの扱いをまとめる。録音で測る項目の定義は、リポジトリの `docs/measure.md` にだけある。このファイルは測定の定義を持たない。

資料の呼び名と由来の書き方は [README.md](README.md) にある。

## 協会の資料

### 5・3・1・6の方式

- 1組は、前の札の下の句、余韻、間合い、次に読む札（出札）の上の句の順に続く。標準の長さは、下の句が5秒程度、余韻が3.0秒、間合いが1.0秒、上の句が6秒程度である。この形を「5・3・1・6方式」と呼ぶ（完全版 p.3。抜粋版も同じページ）。
- 読手の基本の1つとして、読む速さ、余韻、間合いをこの標準に合わせる（完全版 p.2）。
- 下の句の5秒程度は、余韻に入る前までの長さを指す（完全版 p.26）。
- 下の句と上の句を「程度」と幅のある言い方にしているのは、句の途中の伸ばし方が読手ごとに違うからである。会場の広さ、声の大きさや高さ、息の吸い方でも長さは変わる（完全版 p.26）。
- 2020年の改訂の前は「4・3・1・5方式」と呼んでいた。名前を変えたのは読む速さを変えたからではない。大きな会場で伸ばしが長くなり、下の句が5秒、上の句が6秒を超える読みが増えていたので、名前を実態に合わせた（完全版 p.26、講習資料 s.27）。すでにこの長さで読んでいる人は、読み方を変えなくてよい（講習資料 s.27）。
- 4つのうち、余韻と間合いは、競技者がタイミングを合わせるうえでとくに大事なので、毎回同じ長さに保つ（講習資料 s.9）。公認読手の審査でも、余韻と間合いは決まり字までの読みと並んでとくに重く見る項目である（講習資料 s.15-16）。審査の項目は [minimum.md](minimum.md) にある。

### 余韻

- 余韻は、下の句の最後の音を伸ばしていく部分である。完全版 p.3 の図は、例の下の句の最後の字「つ」の所から余韻の3.0秒を示している。講習資料も、余韻の3.0秒は最後の字を含めて数えると説明する（完全版 p.3、講習資料 s.8）。
- 余韻の長さは、1首ごとにぶれないようにする（講習資料 s.7、s.23）。
- 競技者が集中しやすい余韻は、途中で急に途切れず、すっと消えていく。消えていく間に母音の音が変わらない（講習資料 s.24）。
- 講習資料は、余韻の音量の変わり方を3つの形にたとえる（講習資料 s.25）。
  - にんじん型：余韻に入ったら早めに弱め始める。講習資料はこれを理想の消え方と考える。
  - だいこん型：音量を保ったまま続ける。最後に急に切れたり、余韻が長くなったりしやすいので避ける。大きな会場でマイクを使うと、響きが残りやすい。
  - さつまいも型：余韻に入ってから音量が大きくなる。自然に消えて聞こえるよう工夫する。
- 余韻の切れ目について、競技者の好みは分かれる。切れ目が分からないくらいがよいという人も、はっきり聞こえる方がよいという人もいて、全員の望みには応えられない。講習資料は、にんじん型を基本にして違和感を与えないようにする、という考え方を示す（講習資料 s.25）。
- 母音を変えずに消すには、口の形と舌の位置を保ったまま、腹の力で支えて弱めていく。口の形が変わっていないかは鏡で確かめる（講習資料 s.25）。
- 競技者は、読みが下の句の余韻に入ったら、声を出したり畳を叩いたりしてはならない（完全版 p.36、p.37。いずれも競技規程と細則の抜粋）。

### 間合い

- 間合いは、余韻が終わってから次の札の上の句を読み始めるまでの間で、標準は1.0秒である（完全版 p.3）。
- 余韻と同じく、毎回同じ長さに保つ（講習資料 s.23）。
- 息を吸ってから読み始めると、およそ1秒になる。次に述べる数え方と合わせて使える（講習資料 s.23）。
- 審査では、間合いに息を吸う音や音漏れなどの雑音が入っていないかも見る（講習資料 s.15）。
- 上の句の前の息の吸い方と口の形の作り方は [voice.md](voice.md) にある（完全版 p.27）。

### 長さを毎回そろえる方法

- 余韻と間合いを一定にするやり方は人によって合うものが違う。自分に合う方法を探す（講習資料 s.23）。
- 1つの方法として、秒針のある時計で1秒の感覚を覚え、指先で3回刻んで余韻を3秒にする。間合いの1秒を足すと、余韻と間合いで4回、4.0秒になる。慣れると指を使わず頭の中で数えられるようになり、やがて数えなくてもよくなる（講習資料 s.23）。
- 句の途中の伸ばしが長すぎても短すぎても、5・3・1・6の釣り合いが崩れ、競技者が合わせにくくなる（講習資料 s.8）。審査の「全体的なバランス」は、伸ばしの長さが極端でないかを見る（講習資料 s.15）。

## 読手のメモ（読手個人のやり方）

協会の基準ではなく、A級公認読手が自分のやり方として書いたものである。

- 初めて読む人が大事にすることの2つ目に、余韻3秒と間1秒を挙げる（メモ1 要点2）。
- 大会で読むときも、余韻3秒と間1秒が毎回変わらないことは譲れないとする（メモ2 2-2）。
- 余韻の間に、おなかが鳴るなどの物音を立てない。選手の集中を妨げる（メモ2 最後に）。

## 作者の見解

協会の資料でも読手のメモでもなく、このアプリの作者の個人の考えである。答えるときも、作者の考えとして書く。

- 余韻で声を弱めて消す形（デクレシェンド）は、最後の音の母音（あ・い・う・え・お）と「ん」で違う。慣れていない音では、弱めきる前に声が途切れ、余韻が想定より早く切れやすい（段差のように落ちる）。きれいに弱めて消せるよう、最後の音ごとに部分練習するとよい。音ごとの口と舌の形は [mouth-shapes.md](mouth-shapes.md) にある。
- 最後の音ごとの札の数は書き写さず、表 `.claude/skills/yomimasu/assets/cards.json` の各札の結句の発音（`phrases[4].sound`）の最後の字から数える。「ー」で終わるときは、その前の字の母音で数える。「ん」は1つとして数え、発音の種類には触れない。「ん」の前の音ごとの内訳（らん、なん など）は [mouth-shapes.md](mouth-shapes.md) に書き写してあり、リポジトリのテストが表と照らしている。
