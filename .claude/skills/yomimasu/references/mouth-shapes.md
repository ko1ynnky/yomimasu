# 口の形と「ん」の位置

余韻で伸ばす最後の音（あ・い・う・え・お・ん）の口と舌の形と、発話の終わりの「ん」が口の中のどこで作られるかをまとめる。一般の音声学の公開の資料と、「ん」を実測した研究から書いた。読手テキストの調音点・調音法の一覧と口腔断面図は使っていない。

競技かるたの読みで口の形や「ん」の位置を確かめた研究は、このファイルを書くための調査では見つからなかった。下の研究は、話し言葉か歌を調べたものである。読みでも同じになるとは言えない。答えるときは、「研究でわかっていること」「このアプリの解釈」「作者の見解」を分けて伝える。

行の終わりの［1］のような番号は、末尾の「出典」の番号である。資料の呼び名の決まりは [README.md](README.md) にある。

## 一般の音声学

### 母音の違いを決めるもの

- 母音の違いは、舌の高さ、舌の前後の位置、唇の丸めで決まる。開いた母音では、あごが開き、舌は低い［3］。

### 日本語の5つの母音

| 音 | 記号 | 舌 | 唇 |
| --- | --- | --- | --- |
| あ | [a] | 低く、前後のまん中にある | あごを下げて大きく開く |
| い | [i] | 前の方が高い | 丸めない。開きは狭い |
| う | [ɯ] | 奥の方が高い | 丸めないか、唇の両端を寄せる程度で、前に突き出さない |
| え | [e] | 前の方で、中くらいの高さにある | 丸めない。中くらいに開く |
| お | [o] | 奥の方で、中くらいの高さにある | 丸める。丸めは弱い |

出典は［1］［2］［3］。「え」と「お」の記号は、正確には少し低い位置を表す [e̞] [o̞] で書かれる［1］。

### 鼻音

「ん」の研究を読むのに要る分だけを書く。子音の調音点と調音法の一覧は、このフォルダーに入れていない。

- 鼻音は、軟口蓋（上あごの奥のやわらかい所）を下げて息を鼻へ通し、口の中は唇か舌で閉じて作る音である［4］。
- 口の中のどこで閉じるかで名前が分かれる。唇を閉じれば両唇鼻音 [m]、舌の先を歯茎に付ければ歯茎鼻音 [n]、舌の奥を軟口蓋に付ければ軟口蓋鼻音 [ŋ]、舌の奥を口蓋垂に付ければ口蓋垂鼻音 [ɴ] である［4］［5］［6］。
- 口の中を閉じず、息を鼻にも通して出す母音を、鼻母音と呼ぶ［4］。

## 研究でわかっていること

### 発話の終わりの「ん」は、1つの位置に決まらない

- 後に何も続かない「ん」は、教科書類では口蓋垂鼻音とされてきた［7］［8］。
- 東京方言の男性3人を rtMRI（動く MRI）で調べた研究では、発話の終わりの「ん」で舌が閉じる所は、硬口蓋、軟口蓋、口蓋垂にまたがった。この研究は、決まった位置を定めようとすることは役に立たないと結論した［8］。
- 同じ研究計画の報告書は、東京方言の8人の rtMRI のデータで、口蓋垂という定説が成り立たないことが分かったとまとめている［7］。
- X線マイクロビームで17人（関東10人、関西5人、東北2人）の語末の「ん」を調べた研究では、調べた発音（話者と語の組）の 75% が口蓋垂鼻音らしくなく、40% で唇が閉じていたとみられた。この研究は、話者の間に共通の位置はないと述べる。語は「みかん」「きりん」「新聞」「風船」で、ほかの6〜7語と短い間を置いて読んだ録音である［9］。
- 同じ研究では、「みかん」で歯茎鼻音に近い舌の位置の話者もいた。語が変わっても位置が似ている話者と、語ごとに位置が変わる話者がいた［9］。
- 超音波で8人を調べた研究は、「あ」の後の発話の終わりの「ん」の位置が、人によって歯茎から口蓋垂まで変わったと報告する。読んだのは要旨だけである［10］。
- 「ン」を単独で言ったときの rtMRI の予備的な報告では、4人のうち東京の2人が唇を閉じた [m]、大阪の1人が硬口蓋鼻音に近い音、もう1人が歯茎鼻音 [n] で、著しい個人差があった［11］。

### 口の中を閉じない「ん」もある

- rtMRI の研究では、口の中を閉じずに鼻にかかった母音になった例があり、分析から外した。閉じない人がいたという報告ではなく、そうした例があったという報告である［8］。
- 東京の話し言葉の「ん」を、子音ではなく鼻母音として表す研究もある［12］。

### 方言と個人差

- X線マイクロビームの研究では、口蓋垂鼻音らしくない発音の割合は、関東 74%、関西 62%、東北 100% で、方言の群による明らかな違いは見られなかった［9］。
- 東京、大阪、鹿児島の方言を比べた研究は、「ん」の音韻の表し方が方言で違うと提案する。東京は鼻母音、大阪は音節になる鼻音、鹿児島は子音である［12］。
- 同じ研究は、文字どおりの発音、詩の朗読、歌のような強調した発音では、「ん」が日常の会話と違う形になることがあり、分けて扱うべきだとする。挙げる例は語の途中の「ん」である［12］。

### 前の母音との関係（研究で食い違う）

2つの研究の結論が違う。どちらが正しいかは、ここでは決めない。方法、人数、語が違う。

- rtMRI の研究（東京方言の男性3人）は、発話の終わりの「ん」の位置は、前の母音からかなり予測できるとした。舌は前の母音の位置から上へ、ときに奥へ動いて閉じる。「う」の後はほとんど動かず、「い」と「え」の後は短く奥と上へ、「お」の後は真上へやや大きく動いた。「あ」の後は動きが最も大きく、向きが2通りに分かれ、位置も最も散らばった［8］。
- 同じ研究計画の報告書は、東京方言の8人のデータで、発話の終わりの「ん」の位置は前の母音の構えでほぼ全面的に決まるとまとめている［7］。
- X線マイクロビームの研究（17人）では、「きりん」で話者の間の位置がそろった。研究は理由の1つとして前の高い母音「い」を挙げたが、ほかの3語では前の母音の効果を確かめられなかったとした［9］。

### 歌で伸ばした「ん」

- プロのソプラノ歌手に、母音と「ん」を同じ高さで約2秒ずつ歌わせた研究では、ほとんどの場合、「ん」は前の母音より、聞き分けられるほど低くなっていた。下がり方は、「ん」の種類や音の高さより、歌手による違いが大きかった。前の母音の違いによる効果は認められなかった［13］。
- この研究の「ん」は、[m] [n] [ŋ] の3種類を作り分けて歌ったものである。発話の終わりの「ん」を、そのまま伸ばしたものではない［13］。
- 伸ばすこと自体で唇を閉じるようになるかを、直接確かめた実験は、このファイルを書くための調査では見つからなかった。

## 序歌と100首の「ん」で終わる札

結句の最後の音（伸ばす「ー」を除く）が「ん」の札である。表 `assets/cards.json` の結句の `sound` の最後の字で数えた。どの札も、表の結句の仮名（`kana`）は「む」で終わる。序歌は「ん」で終わらない。

<!-- 「ん」で終わる札：この表は test/skill/mouth-shapes.test.ts が札の読みの表と照らす -->
| 最後の2音 | 前の母音 | 札 |
| --- | --- | --- |
| らん | あ | 18、22、27、33、36 |
| なん | あ | 26、73 |
| ねん | え | 3、91 |
| こん | お | 16 |
| めん | え | 12 |

合わせて11首で、前の母音は「あ」が7首、「え」が3首、「お」が1首である。

## このアプリの解釈

研究にはない、このアプリの考えである。答えるときは、研究の結論と分けて伝える。

- 余韻で母音の音を変えずに消すこと、そのために口の形と舌の位置を保って弱めること、口の形を鏡で確かめることは、協会の資料にある（講習資料 s.24-25。[timing.md](timing.md) にある）。このアプリの解釈は、そのうえで音ごとに何を保つかを、母音の違いを決める舌と唇の形（一般の音声学）から当てた次の表と、それを「ん」に当てはめた所である。

  | 音 | 弱めて消す間に保つ所 |
  | --- | --- |
  | あ | あごを下げた口の開き |
  | い | 舌の前の高さと、丸めない唇の狭い開き |
  | う | 舌の奥の高さと、突き出さない唇の小さな開き |
  | え | 中くらいの開きと、舌の前の位置 |
  | お | 唇の丸めと、舌の奥の位置 |
  | ん | 自分の閉じ方と、鼻へ抜ける息 |

- 話し言葉の研究では、発話の終わりの「ん」の位置は1つに決まらない。読みで決まった位置があるかは、研究からは言えない。そこで、決まった位置をまねるより、自分の「ん」がどこで閉じているかを知り、余韻の間、その閉じ方と鼻へ抜ける息を変えない。研究では語ごとに位置が変わる話者もいたので、「ん」で終わる札ごとに確かめる。
- 自分の閉じ方は、「ん」を伸ばしながら鏡で唇を見ると、唇を閉じているかが分かる（鏡で口の形を確かめる方法は講習資料 s.25 にある）。伸ばしている途中で鼻をつまみ、音が止まれば、口の中のどこかで閉じている。鼻音は、息が鼻からしか出ないからである。
- 「ん」で終わる札の前の母音を、rtMRI の研究に当てはめると、「らん」「なん」は位置が散らばりやすく、「ねん」「めん」「こん」は前の母音の位置から上へ動く、と読める。しかし X線マイクロビームの研究は「きりん」のほかで前の母音の効果を確かめられず、読みで確かめた研究もこの調査では見つからなかった。そのため、前の母音で「ん」の位置を決めて練習することは勧めない。

## 作者の見解

- 余韻で声を弱めて消す形は、最後の音の母音（あ・い・う・え・お）と「ん」で違う。慣れていない音では、弱めきる前に声が途切れ、余韻が思ったより早く切れやすい。最後の音ごとに部分練習するとよい。もとの文は [timing.md](timing.md) の「作者の見解」にある。
- 作者の観察：作者は、「らむ」（発音は「らん」）では唇を閉じ、12番（あまつ）の結句の終わりの「めむ」（発音は「めん」）と、91番（きり）の結句の終わりの「ねむ」（発音は「ねん」）では閉じていない。91番と同じ結句「ひとりかも寝む」は3番にもあるが、作者が挙げたのは91番である。自分で読んで、唇を閉じているかが分かる例である。研究の結論ではない。「らむ」がどの札のものかは特定していない。作者は、発話の終わりの「ん」に1つの位置がなく唇を閉じる人もいるという研究の結果が、自分の感覚と合っていると述べている。読みで研究を確かめたものではない。
